Dart Lists

1. What Is a List?

A List is an ordered collection of values. It is similar to an array or list structure you may have used in other programming languages.

  • Elements are stored in a specific order.
  • Each element has an index.
  • Dart List indexes start at 0.
  • A List can contain duplicate values.
  • A typed List can restrict all elements to a particular data type.
  • Lists are extremely common in applications—for example, courses, products, messages, tasks, names, and scores.

First Example

void main() {
  List<String> courses = ['Dart', 'Flutter', 'Database'];

  print(courses);
}
[Dart, Flutter, Database]

2. Creating Lists

A. Explicitly Typed List

List<String> names = ['Ana', 'Jordan', 'Sam'];
List<int> scores = [90, 85, 100];
List<double> prices = [12.50, 9.99, 20.00];

List<String> means the List is intended to contain Strings. Similarly, List<int> contains integers.

B. Let Dart Infer the Type

var names = ['Ana', 'Jordan', 'Sam'];
var scores = [90, 85, 100];
Dart-specific point: With these initializers, Dart infers names as a String List and scores as an int List. Using var does not mean the variable is freely typeless.

C. Empty List

List<String> courses = [];
List<int> scores = [];

D. Empty List with Type Argument on the Literal

var courses = <String>[];
var scores = <int>[];

3. List Indexes

Indexes begin at zero.

ElementIndex
Dart0
Flutter1
Database2
void main() {
  List<String> courses = ['Dart', 'Flutter', 'Database'];

  print(courses[0]);
  print(courses[1]);
  print(courses[2]);
}
Dart Flutter Database
Common error: If a List has three elements, index 3 is invalid. The valid indexes are 0, 1, and 2. An invalid index can cause a RangeError at runtime.

4. Updating an Element

void main() {
  List<String> courses = ['Dart', 'Flutter', 'Database'];

  courses[2] = 'Artificial Intelligence';

  print(courses);
}
[Dart, Flutter, Artificial Intelligence]

The List still has three elements. We replaced the value at index 2.

10. Removing Elements

remove(value)

var courses = ['Dart', 'Flutter', 'Database'];

courses.remove('Flutter');

print(courses);
[Dart, Database]

remove() removes the first occurrence of the specified value and returns a Boolean indicating whether a matching element was removed.

removeAt(index)

var courses = ['Dart', 'Flutter', 'Database'];

String removedCourse = courses.removeAt(1);

print(removedCourse);
print(courses);
Flutter [Dart, Database]

removeLast()

var numbers = [10, 20, 30, 40];

int removed = numbers.removeLast();

print(removed);
print(numbers);
40 [10, 20, 30]

removeWhere()

var scores = [55, 80, 62, 95, 40];

scores.removeWhere((score) => score < 70);

print(scores);
[80, 95]

clear()

var courses = ['Dart', 'Flutter', 'Database'];

courses.clear();

print(courses);
print(courses.isEmpty);
[] true

11. Searching a List

contains()

var courses = ['Dart', 'Flutter', 'Database'];

print(courses.contains('Flutter'));
print(courses.contains('Java'));
true false

indexOf()

var courses = ['Dart', 'Flutter', 'Database'];

print(courses.indexOf('Flutter'));
print(courses.indexOf('Java'));
1 -1
indexOf() returns -1 when the requested value is not found.

12. Looping Through a List with for-in

void main() {
  var courses = ['Dart', 'Flutter', 'Database'];

  for (String course in courses) {
    print(course);
  }
}
Dart Flutter Database

Use for-in when you need each element directly and do not need its index.

13. Looping with an Index

void main() {
  var courses = ['Dart', 'Flutter', 'Database'];

  for (int i = 0; i < courses.length; i++) {
    print('$i: ${courses[i]}');
  }
}
0: Dart 1: Flutter 2: Database

This form is useful when both the position and the value matter.

14. forEach()

var courses = ['Dart', 'Flutter', 'Database'];

courses.forEach((course) {
  print(course);
});

forEach() calls a function for every element.

Loop-control note: If you need normal break or continue behavior, a regular for or for-in loop is usually a better choice than forEach().

15. Lists with if, break, and continue

Skip a Particular Value with continue

var courses = ['Dart', 'Flutter', 'Database', 'AI'];

for (String course in courses) {
  if (course == 'Database') {
    continue;
  }

  print(course);
}
Dart Flutter AI

Search and Stop with break

var courses = ['Dart', 'Flutter', 'Database', 'AI'];

for (String course in courses) {
  if (course == 'Database') {
    print('Found: $course');
    break;
  }
}
Found: Database

16. where() — Filter a List

void main() {
  var scores = [55, 72, 88, 61, 95];

  var passingScores =
      scores.where((score) => score >= 70).toList();

  print(passingScores);
}
[72, 88, 95]

where() returns the elements satisfying the condition. It returns an Iterable; toList() converts that result into a List.

17. map() — Transform Every Element

void main() {
  var numbers = [1, 2, 3, 4];

  var squares =
      numbers.map((number) => number * number).toList();

  print(squares);
}
[1, 4, 9, 16]

Another map() Example

var names = ['ana', 'sam', 'jordan'];

var upperNames =
    names.map((name) => name.toUpperCase()).toList();

print(upperNames);
[ANA, SAM, JORDAN]
Do not confuse these: map() is a transformation method. Dart also has a separate Map collection type for key-value data.

18. firstWhere() — Find the First Matching Element

var courses = ['Dart', 'Flutter', 'Database'];

var result = courses.firstWhere(
  (course) => course.startsWith('F'),
  orElse: () => 'Not Found',
);

print(result);
Flutter

24. Growable and Fixed-Length Lists

Growable List

var numbers = [10, 20, 30];

numbers.add(40);
numbers.remove(20);

print(numbers);
[10, 30, 40]

Fixed-Length List

var numbers =
    List<int>.filled(3, 0, growable: false);

numbers[0] = 10; // valid
numbers[1] = 20; // valid

// numbers.add(30); // Unsupported operation

A fixed-length List allows element replacement, but its number of positions cannot be changed.

25. final List vs const List

final List

final numbers = [1, 2, 3];

numbers.add(4);       // valid
numbers[0] = 100;     // valid

// numbers = [9, 10]; // invalid: variable cannot be reassigned

final prevents the variable from referring to another List, but it does not automatically make the List object immutable.

const List

const numbers = [1, 2, 3];

// numbers.add(4);   // invalid at runtime: const list is unmodifiable
// numbers[0] = 10; // invalid at runtime

26. Copying Lists — A Very Important Concept

void main() {
  var original = [10, 20, 30];
  var another = original;

  another.add(40);

  print(original);
  print(another);
}
[10, 20, 30, 40] [10, 20, 30, 40]

Both variables refer to the same List object.

Create a Separate Shallow Copy

var original = [10, 20, 30];
var copy = [...original];

copy.add(40);

print(original);
print(copy);
[10, 20, 30] [10, 20, 30, 40]

27. Spread Operator (...)

var requiredCourses = ['Dart', 'Database'];
var electives = ['AI', 'Networks'];

var allCourses = [
  ...requiredCourses,
  ...electives,
];

print(allCourses);
[Dart, Database, AI, Networks]

28. Null-Aware Spread Operator (...?)

List<String>? electives;

var courses = [
  'Dart',
  'Database',
  ...?electives,
];

print(courses);
[Dart, Database]

If electives is null, the null-aware spread simply adds nothing.

33. Practical Example — Display Only Available Courses

void main() {
  List<Map<String, dynamic>> courses = [
    {'name': 'Dart', 'credits': 4, 'available': true},
    {'name': 'Database', 'credits': 4, 'available': false},
    {'name': 'AI', 'credits': 4, 'available': true},
  ];

  for (var course in courses) {
    if (course['available'] == false) {
      continue;
    }

    print('${course['name']} - ${course['credits']} credits');
  }
}

36. Practical Example — Search for a Course

void main() {
  var courses = ['Dart', 'Database', 'AI', 'Networks'];

  String searchCourse = 'AI';
  bool found = false;

  for (String course in courses) {
    if (course == searchCourse) {
      found = true;
      print('$searchCourse was found.');
      break;
    }
  }

  if (!found) {
    print('$searchCourse was not found.');
  }
}

37. Practical Example — Registration Credit Limit

void main() {
  List<Map<String, dynamic>> courses = [
    {'name': 'Dart', 'credits': 4},
    {'name': 'Database', 'credits': 4},
    {'name': 'Networks', 'credits': 4},
    {'name': 'AI', 'credits': 4},
    {'name': 'Cybersecurity', 'credits': 3},
  ];

  const int maxCredits = 16;
  int totalCredits = 0;
  List<String> selectedCourses = [];

  for (var course in courses) {
    int credits = course['credits'];

    if (totalCredits + credits > maxCredits) {
      print('Cannot add ${course['name']}. Credit limit reached.');
      break;
    }

    selectedCourses.add(course['name']);
    totalCredits += credits;
  }

  print('Selected: $selectedCourses');
  print('Total credits: $totalCredits');
}

39. Common Errors

Error 1: Wrong Index

var courses = ['Dart', 'Flutter'];

// print(courses[2]); // RangeError

Error 2: Wrong Element Type

List<int> scores = [80, 90];

// scores.add('100'); // compile-time type error
scores.add(100);      // correct

Error 3: Assuming var Means dynamic

var scores = [80, 90];

// scores = ['A', 'B']; // incompatible with inferred List<int>

Error 4: Modifying a const List

const courses = ['Dart', 'Flutter'];

// courses.add('Database'); // not allowed

Error 5: Forgetting toList()

var scores = [50, 80, 90];

Iterable<int> result =
    scores.where((score) => score >= 70);

List<int> passingScores = result.toList();

41. Key Takeaways

  • A Dart List is an ordered, zero-indexed collection.
  • List<T> specifies the type of elements the List should contain.
  • Use indexes to read or replace individual elements.
  • Growable Lists support adding and removing elements.
  • Dart provides useful operations for searching, filtering, transforming, sorting, and generating Lists.
  • where(), map(), firstWhere(), any(), and every() are especially useful for application data.
  • Lists work naturally with if, loops, break, and continue.
  • Later, the same Dart List data and logic can be connected to Flutter UI components.
At this stage, focus on understanding the Dart data and logic. When Flutter is introduced, Lists can provide the data used to build screens such as course lists, task lists, menus, product lists, and search results.

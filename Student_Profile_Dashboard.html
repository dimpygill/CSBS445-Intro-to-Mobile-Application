Instructions

  1. Create a Flutter Dart program with an AppBar titled Student Profile.
  2. Use a Row to display a profile Icon beside a nested Column containing a sample student name and major.
  3. Add a Card showing at least three academic details, such as student ID, semester, and GPA.
  4. Display three course names horizontally in a Row.
  5. Use Padding, SizedBox, or spacing to make the layout readable. You may choose your own colors and sample data.
  6. Run the application in the Flutter emulator and capture a screenshot showing the completed interface.

Submission

Upload both files to Canvas:

  1. student_profile.dart — your complete Flutter source code.
  2. student_profile.png — a screenshot of the application running in the emulator.

Grading: 1 point for submitting both the Dart file and a screenshot demonstrating your in-class work. Exact colors, wording, and pixel-perfect positioning are not required.

Helpful hints

Show layout hints

Start with MaterialApp → Scaffold → Padding → Column. Inside the main Column, place a Row for the profile header. Inside that Row, use an Icon and a second Column for the student name and major. Add a Card for academic information and another Row for course names. If the content is too tall, use SingleChildScrollView.

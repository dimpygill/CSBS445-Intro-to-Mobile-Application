  • Add a new task (name + priority)

🗄️ Step 2

Set Up the MS SQL Database

Create the database and the Tasks table. This is where all task data will be permanently stored.

🗄️
What tool to use: Open SQL Server Management Studio (SSMS) and connect to your local SQL Server instance.
1
Create the Database
Run this SQL to create a new database called TaskManagerDB
📄 SQL — Create Database
CREATE DATABASE TaskManagerDB; USE TaskManagerDB;
StatementWhat It Does
CREATE DATABASE TaskManagerDBCreates a brand new empty database with this name
USE TaskManagerDBSwitches to that database so the next statements run inside it
2
Create the Tasks Table
Run this SQL to create the table that stores all tasks
📄 SQL — Create Table
CREATE TABLE Tasks ( id INT IDENTITY(1,1) PRIMARY KEY, taskName NVARCHAR(200) NOT NULL, priority NVARCHAR(20) NOT NULL DEFAULT 'Medium', isDone BIT NOT NULL DEFAULT 0 );
PartWhat It Means
INT IDENTITY(1,1)Automatically creates a new number for each row: 1, 2, 3 ...
PRIMARY KEYMakes id the unique identifier — no two tasks can have the same id
NVARCHAR(200)Text up to 200 characters long. N means it supports all languages.
NOT NULLThis field is required — you cannot leave it empty
DEFAULT 'Medium'If no priority is provided, the database automatically uses "Medium"
BITStores only 0 (false/not done) or 1 (true/done)
DEFAULT 0Every new task starts as not done (0)
3
Add Some Test Data
Insert a few rows to verify the table works correctly
📄 SQL — Insert Test Rows
INSERT INTO Tasks (taskName, priority, isDone) VALUES ('Math homework', 'High', 0), ('Read Chapter 4', 'Medium', 0), ('Submit project', 'High', 1);
📄 SQL — Check the Data
SELECT * FROM Tasks;
✅
You should see 3 rows appear in SSMS. If you do, the database is working correctly. Notice that id was automatically set to 1, 2, 3 — you never had to set it yourself.

What Is Git? What Is GitHub?

Git vs GitHub
🐙
Git
The tool on your computer that tracks changes to your code
≠
🌐

A website that stores your code online so you can share it

Think of Git as your save history — every time you commit, Git takes a snapshot of your code. GitHub is like a cloud drive that stores all those snapshots online.

Write the Task Class

// A Task object represents one row from the database class Task { int id; String taskName; String priority; bool isDone; // Constructor — creates a Task object Task({ required this.id, required this.taskName, required this.priority, required this.isDone, }); // Factory — converts a database row (Map) into a Task object factory Task.fromMap(Map<String, dynamic> row) { return Task( id: row['id'], taskName: row['taskName'], priority: row['priority'], isDone: row['isDone'] == 1, // BIT 0/1 → Dart bool ); } }
PartPlain English Meaning
class TaskDefine a blueprint for what a Task looks like in code
int id;Every task has an integer ID that matches the database row
required this.taskNametaskName is a required field — you must provide it when creating a Task
factory Task.fromMap()A special way to create a Task from a Map (which is what the database returns)
row['isDone'] == 1The database stores 0 or 1. We convert: 1 → true, 0 → false

Connect Flutter to MS SQL Server

Write the database service — the code that opens a connection and runs SQL queries.

1
Create the Database Service File

2
Write the Database Service
lib/services/database_service.dart — the full file
📄 lib/services/database_service.dart
import 'package:mssql_connection/mssql_connection.dart'; import '../models/task.dart'; class DatabaseService { // ── CONNECTION SETTINGS ───────────────────────── static const String _server = 'localhost'; static const String _database = 'TaskManagerDB'; static const String _username = 'your_sql_username'; static const String _password = 'your_sql_password'; late MssqlConnection _connection; // ── OPEN CONNECTION ───────────────────────────── Future<void> connect() async { _connection = MssqlConnection.getInstance(); await _connection.connect( ip: _server, port: '1433', databaseName: _database, username: _username, password: _password, ); } // ── GET ALL TASKS ──────────────────────────────── Future<List<Task>> getTasks() async { final result = await _connection.getData( 'SELECT id, taskName, priority, isDone FROM Tasks' ); return result.map((row) => Task.fromMap(row)).toList(); } // ── ADD A TASK ─────────────────────────────────── Future<void> addTask(String name, String priority) async { await _connection.writeData( "INSERT INTO Tasks (taskName, priority) VALUES ('$name', '$priority')" ); } // ── MARK TASK DONE ─────────────────────────────── Future<void> markDone(int id, bool isDone) async { int bit = isDone ? 1 : 0; await _connection.writeData( 'UPDATE Tasks SET isDone = $bit WHERE id = $id' ); } // ── DELETE A TASK ──────────────────────────────── Future<void> deleteTask(int id) async { await _connection.writeData( 'DELETE FROM Tasks WHERE id = $id' ); } }
FunctionWhat SQL It RunsReturns
connect()Opens the connection to SQL ServerNothing — just connects
getTasks()SELECT all rows from TasksA List of Task objects
addTask()INSERT a new row into TasksNothing — just inserts
markDone()UPDATE isDone for a specific rowNothing — just updates
deleteTask()DELETE a row by its idNothing — just deletes
⚠️
Replace the connection settings! Change 'your_sql_username' and 'your_sql_password' to your actual SQL Server credentials from Step 2.
🔍
What is async / await?
Connecting to a database takes a moment. async tells Dart "this function might take time." await tells Dart "wait here until the database responds before continuing." Without these, the app would try to use data before it had arrived.

import 'package:flutter/material.dart'; import '../models/task.dart'; import '../services/database_service.dart'; import 'add_task_screen.dart'; class HomeScreen extends StatefulWidget { const HomeScreen({super.key}); @override State<HomeScreen> createState() => _HomeScreenState(); } class _HomeScreenState extends State<HomeScreen> { final DatabaseService _db = DatabaseService(); List<Task> _tasks = []; bool _loading = true; @override void initState() { super.initState(); _loadTasks(); } // ── Load all tasks from the database ───────────── Future<void> _loadTasks() async { await _db.connect(); final tasks = await _db.getTasks(); setState(() { _tasks = tasks; _loading = false; }); } // ── Toggle a task done/undone ───────────────────── Future<void> _toggleDone(Task task) async { await _db.markDone(task.id, !task.isDone); _loadTasks(); } // ── Delete a task ───────────────────────────────── Future<void> _deleteTask(int id) async { await _db.deleteTask(id); _loadTasks(); } @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar( title: const Text('📋 My Tasks'), backgroundColor: Colors.indigo, foregroundColor: Colors.white, ), // ── Show spinner while loading ───────────────── body: _loading ? const Center(child: CircularProgressIndicator()) : _tasks.isEmpty ? const Center(child: Text('No tasks yet. Tap + to add one.')) : ListView.builder( itemCount: _tasks.length, itemBuilder: (context, index) { final task = _tasks[index]; return ListTile( // ── Checkbox on the left ──────────────── leading: Checkbox( value: task.isDone, onChanged: (_) => _toggleDone(task), ), // ── Task name (strike-through if done) ── title: Text( task.taskName, style: TextStyle( decoration: task.isDone ? TextDecoration.lineThrough : TextDecoration.none, color: task.isDone ? Colors.grey : Colors.black, ), ), subtitle: Text(task.priority), // ── Delete button on the right ────────── trailing: IconButton( icon: const Icon(Icons.delete, color: Colors.red), onPressed: () => _deleteTask(task.id), ), ); }, ), // ── Floating + button → navigates to Add screen ── floatingActionButton: FloatingActionButton( backgroundColor: Colors.indigo, child: const Icon(Icons.add, color: Colors.white), onPressed: () async { await Navigator.push( context, MaterialPageRoute(builder: (_) => const AddTaskScreen()), ); _loadTasks(); // refresh after returning }, ), ); } }

StatefulWidgetThis screen can change — it holds a list of tasks that updates
initState()Runs once when the screen opens — loads tasks from database
setState()Tells Flutter "the data changed — please redraw the screen"
CircularProgressIndicatorThe spinning wheel shown while data is loading
ListView.builderCreates a scrollable list — one item per task
ListTileOne row in the list: checkbox + task name + delete button
TextDecoration.lineThroughStrikes through the text when a task is done

Basic If / If-Else

1
🟢 Beginner
Pass or Fail
A student passes if their marks are 40 or above.
Write a program with a variable marks = 75. Print "Pass" if marks are 40 or above, otherwise print "Fail".
Student's marks ↓ marks >= 40? / \ YES NO ↓ ↓ "Pass" "Fail"
if-elsecomparison operatorbool
Hint: Use >= to mean "greater than OR equal to". > alone would miss students with exactly 40 marks.
✅ Solution
void main() { int marks = 75; if (marks >= 40) { print("Pass"); } else { print("Fail"); } }
Output
Pass
Why >=? The requirement says "40 or above." >= means "greater than OR equal to." If we used >, a student with exactly 40 marks would wrongly print "Fail."
2
🟢 Beginner
Even or Odd
Write a program with a variable number = 14. Print "Even" if the number is divisible by 2, otherwise print "Odd".
if-else% operator
Hint: The % operator gives the remainder after division. If number % 2 == 0, there is no remainder — the number is even.
✅ Solution
void main() { int number = 14; if (number % 2 == 0) { print("Even"); } else { print("Odd"); } }
Output
Even
14 % 2 = 0 because 14 divides evenly by 2. If the remainder is 0, the number is even. Try changing to 15 — the remainder would be 1, so "Odd" would print.
3
🟢 Beginner
Task Status
Create a bool variable taskDone = false. If taskDone is true, print "✅ Completed". Otherwise print "⬜ Still to do".
boolif-else
✅ Solution
void main() { bool taskDone = false; if (taskDone) { print("✅ Completed"); } else { print("⬜ Still to do"); } }
Output
⬜ Still to do
Because taskDone is false, the if-block is skipped and the else-block runs. Change to true and "✅ Completed" prints instead.

Else-If Chains — Multiple Categories

4
🟡 Easy
Grade Calculator
A university uses this grading scale: 90+ = A, 80–89 = B, 70–79 = C, 60–69 = D, below 60 = F.
Write a program with marks = 82 and print the correct letter grade.
marks >= 90 → "A" marks >= 80 → "B" marks >= 70 → "C" marks >= 60 → "D" otherwise → "F"
else-ifcomparisonreal-world
Hint: Put the highest grade first. Once Dart finds a true condition, it skips the rest — so ordering matters.
✅ Solution
void main() { int marks = 82; if (marks >= 90) { print("Grade: A"); } else if (marks >= 80) { print("Grade: B"); } else if (marks >= 70) { print("Grade: C"); } else if (marks >= 60) { print("Grade: D"); } else { print("Grade: F"); } }
Output
Grade: B
82 is not ≥90, but it IS ≥80, so "Grade: B" prints and all remaining else-if blocks are skipped.
5
🟡 Easy
Movie Ticket Pricing
A cinema charges: under 12 = $6, 12–17 = $9, 18–64 = $14, 65+ = $8.
Write a program with age = 15 and print the correct ticket price.
else-ifreal-world pricing
Hint: Check the senior age first (age >= 65), or check the youngest first (age < 12). Either order works as long as it's consistent.
✅ Solution
void main() { int age = 15; if (age < 12) { print("Ticket: \$6"); } else if (age <= 17) { print("Ticket: \$9"); } else if (age <= 64) { print("Ticket: \$14"); } else { print("Ticket: \$8"); } }
Output
Ticket: $9

Multiple Conditions — && and ||

6
🔵 Intermediate
Shopping Discount
A customer gets a 15% discount if they are a member AND their purchase total is $100 or above.
Write a program with isMember = true and total = 120.0. Print "Discount applied!" or "No discount."
&& operatormultiple conditionsbool
Hint: && means "AND" — BOTH conditions must be true. Write: if (isMember && total >= 100)
✅ Solution
void main() { bool isMember = true; double total = 120.0; if (isMember && total >= 100) { print("Discount applied!"); } else { print("No discount."); } }
Output
Discount applied!
Why &&? The customer needs BOTH conditions true to qualify. If either is false — not a member, or total under $100 — no discount. Try changing isMember = false and watch the output change.
7
🔵 Intermediate
Course Registration
A student can register for an advanced course if they have completed Prerequisite A OR Prerequisite B (or both).
Write a program with hasPrereqA = false and hasPrereqB = true. Print "Registration allowed" or "Cannot register."
|| operatorbool
Hint: || means "OR" — at least ONE condition needs to be true. if (hasPrereqA || hasPrereqB)
✅ Solution
void main() { bool hasPrereqA = false; bool hasPrereqB = true; if (hasPrereqA || hasPrereqB) { print("Registration allowed"); } else { print("Cannot register"); } }
Output
Registration allowed
Even though hasPrereqA is false, hasPrereqB is true — and || only needs ONE to be true. So "Registration allowed" prints.

Write a program with balance = 300.0 and amount = 150.0. Print "Withdrawal approved" or explain why it was denied.

Common Mistakes — If / Else
  • Using = instead of ==: if (age = 18) ❌ — = assigns; == compares

🐛 Section 6

Debugging — Find and Fix the Errors

Every program below has a mistake. Your job: find it, explain what's wrong, and fix it.

🔍
How to approach debugging: Read the code carefully. Try to predict what it should do. Then look for anything that doesn't look right — wrong type, missing semicolon, wrong operator, etc.
🐛
Bug #1 — Syntax Error
Broken Code
void main() { int age = 20 ← bug here print(age); }
What is wrong? How do you fix it?
✅ Bug Found

Problem: Missing semicolon after int age = 20. Every statement in Dart must end with ;

void main() { int age = 20; ← semicolon added ✅ print(age); }
🐛
Bug #2 — Wrong Type
void main() { int score = "ninety"; print(score); }
✅ Bug Found

Problem: int can only hold whole numbers, not text. "ninety" is a String.

// Fix option 1: use the number int score = 90; // Fix option 2: use a String variable String score = "ninety";
🐛
Bug #3 — Assignment Instead of Comparison
void main() { int age = 20; if (age = 18) { print("Adult"); } }
✅ Bug Found

Problem: age = 18 tries to assign the value 18 to age inside the if condition. To compare, you need == (double equals).

if (age == 18) { ← double equals for comparison ✅ print("Adult"); }
🐛
Bug #4 — Logic Error (code runs, but wrong answer)
Requirement: "Adults are 18 or older."
void main() { int age = 18; if (age > 18) { print("Adult"); } else { print("Minor"); } }

The code runs without errors, but the output is wrong. What's the bug?

✅ Logic Bug Found

Problem: age > 18 means "strictly greater than 18." Someone who is exactly 18 would print "Minor" — which is wrong! The requirement says "18 or older" = >=.

if (age >= 18) { ← >= includes 18 itself ✅ print("Adult"); }
This is a logic error — the most dangerous kind because Dart doesn't warn you. The code runs fine but produces the wrong result. Always re-read the requirements carefully and check boundary values.
🐛
Bug #5 — Missing Curly Braces
void main() { int marks = 55; if (marks >= 40) print("Pass"); print("Well done!"); }

The student expects "Well done!" to only print when marks >= 40. What's wrong?

✅ Bug Found

Problem: Without curly braces, only the first statement after the if belongs to it. "Well done!" always prints, regardless of marks.

if (marks >= 40) { ← add curly braces ✅ print("Pass"); print("Well done!"); }

🎓 Student Grade Calculator
Scenario
A university needs a program to assign letter grades to students based on their exam marks.
Requirements
  • 90–100 → Grade A
  • 80–89 → Grade B
  • 70–79 → Grade C
  • 60–69 → Grade D
  • Below 60 → Grade F
Create a function calculateGrade(int marks) that prints the grade. Test it with marks: 95, 82, 71, 65, 45.
functionelse-ifint
✅ Complete Solution
void calculateGrade(int marks) { if (marks >= 90) { print("Marks: " + marks.toString() + " → Grade A"); } else if (marks >= 80) { print("Marks: " + marks.toString() + " → Grade B"); } else if (marks >= 70) { print("Marks: " + marks.toString() + " → Grade C"); } else if (marks >= 60) { print("Marks: " + marks.toString() + " → Grade D"); } else { print("Marks: " + marks.toString() + " → Grade F"); } } void main() { calculateGrade(95); calculateGrade(82); calculateGrade(71); calculateGrade(65); calculateGrade(45); }
Output
Marks: 95 → Grade A Marks: 82 → Grade B Marks: 71 → Grade C Marks: 65 → Grade D Marks: 45 → Grade F
Concepts used: Function with a parameter, else-if chain. The function can be called as many times as needed — this is exactly how functions save you from repeating code.

✅ Task Manager Logic
Build the core data logic for a Student Task Manager — just the Dart, no Flutter yet.

This combines every concept from the Dart tutorial: class, list, function, bool, and if-else. This is the logic that powers the Task Manager app you'll build in Flutter!

🛍️ Shopping Discount Calculator
An online store applies discounts: spend $200+ and get 20% off; spend $100–$199 and get 10% off; spend $50–$99 and get 5% off; below $50 no discount.

void calculateDiscount(double total) { double discountPct = 0; if (total >= 200) { discountPct = 0.20; } else if (total >= 100) { discountPct = 0.10; } else if (total >= 50) { discountPct = 0.05; } double discountAmt = total * discountPct; double finalPrice = total - discountAmt; print("Total: \$" + total.toString()); print("Discount: " + (discountPct * 100).toString() + "%"); print("You save: \$" + discountAmt.toString()); print("Final: \$" + finalPrice.toString()); print("---"); } void main() { calculateDiscount(250); calculateDiscount(150); calculateDiscount(75); calculateDiscount(30); }

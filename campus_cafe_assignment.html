🆕 Two new widgets

You'll use two widgets you may not have seen before. Here's what they do.

Icon

Shows a built-in picture. Flutter has thousands of them in Icons. (type Icons. in VS Code to see the list).
☕
Icon(Icons.local_cafe, size: 100)
Icon(Icons.local_cafe, size: 100)

Icons.local_cafe picks which picture to show. size: 100 makes it big (the default is 24).

Icons to try: Icons.local_cafe, Icons.menu_book, Icons.star, Icons.cake, Icons.info

SizedBox

An invisible empty box. Put it between widgets in a Column to add space so they don't look squashed.

import 'package:flutter/material.dart';
import 'menu_page.dart';
import 'about_page.dart';

Widget homePage(BuildContext context) {
  return Scaffold(
    appBar: AppBar(title: Text('Campus Café')),
    body: Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(Icons.local_cafe, size: 100),
          Text('Welcome to Campus Café!'),
          Text('Fresh coffee and snacks between classes.'),
          SizedBox(height: 30),
          FilledButton.icon(
            icon: Icon(Icons.menu_book),
            label: Text('View Menu'),
            onPressed: () {
              Navigator.push(
                context,
                MaterialPageRoute(
                  builder: (context) => menuPage(context),
                ),
              );
            },
          ),
          SizedBox(height: 10),
          OutlinedButton.icon(
            icon: Icon(Icons.info),
            label: Text('About Us'),
            onPressed: () {
              // TODO: push the About page (aboutPage)
              //       Copy the push above and change menuPage to aboutPage
            },
          ),
        ],
      ),
    ),
  );
}

Why "Today's Special" uses double quotes: the word Today's has an apostrophe '. With single quotes, Dart would think the text ends there. Double quotes avoid the problem.

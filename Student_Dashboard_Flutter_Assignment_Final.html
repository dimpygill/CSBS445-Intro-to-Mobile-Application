Flutter UI Assignment: My Student Dashboard

Build a simple, single-screen Flutter app that displays a student profile and a three-class schedule. Use the basic layout widgets introduced in the Flutter UI tutorial.

1. Goal

Practice combining Flutter widgets into a complete user interface (UI). The challenge is to arrange information clearly using Column, Row, Container, and spacing widgets. You do not need to build a database, navigate to another screen, or collect user input.

What you will create: A yellow title bar, a profile icon and student information, a heading, three colored class schedule cards, and a button.

3. Required features

  1. App bar: Display My Student Dashboard in a yellow AppBar, with its title centered.
  2. Profile: Show a person icon, a student name, and a short subtitle (for example, Computer Science Student).
  3. Schedule heading: Display My Class Schedule.
  4. Three class cards: Each card must display a day and a course/time. Use three separate Container widgets with different background colors.
  5. Horizontal arrangement: Inside each schedule card, use a Row so the day appears on the left and the course/time on the right.
  6. Spacing: Use SizedBox between major sections, and padding inside the colored cards.
  7. Button: Include an ElevatedButton labeled View Schedule. When clicked, it should print Schedule button clicked in the debug console. It does not need to open another screen.
  8. Personalization: Choose your own profile text and class details. Fictional information is acceptable.

4. Build it step by step

Step 1 — Create or open a Flutter project

Open your Flutter project in VS Code. Open lib/main.dart. Make sure the Material library is imported, and start with main(), runApp(), MaterialApp(), and Scaffold().

Hint: basic app structure
import 'package:flutter/material.dart';

void main() {
  runApp(
    MaterialApp(
      home: Scaffold(
        // Add appBar and body here.
      ),
    ),
  );
}

Step 2 — Add the title bar

Inside Scaffold, use appBar: and add an AppBar with the title and yellow background.

Hint: AppBar parameters
appBar: AppBar(
  backgroundColor: Colors.yellow,
  title: Text('My Student Dashboard'),
  centerTitle: true,
),

Step 3 — Add the profile

In body:, use a Center containing a Column. Add a person Icon followed by two Text widgets.

Hint: one child versus multiple children
body: Center(
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    children: [
      Icon(Icons.person, size: 60, color: Colors.blue),
      Text('Alex Johnson'),
      Text('Computer Science Student'),
      // Add the schedule below.
    ],
  ),
),

Center has one child: the Column. The Column has multiple children.

Step 4 — Build the first schedule card

After the schedule heading, create a colored Container. Its child should be a Row with two Text widgets.

Hint: one schedule card
Container(
  color: Colors.blue[100],
  padding: EdgeInsets.all(12),
  child: Row(
    mainAxisAlignment: MainAxisAlignment.spaceBetween,
    children: [
      Text('Monday'),
      Text('Flutter - 10 AM'),
    ],
  ),
),

spaceBetween places the first item toward the left and the second toward the right of the available row.

Step 5 — Add two more schedule cards

Repeat the same card structure for Wednesday and Friday. Change the day, course/time, and background color. Put a SizedBox(height: 10) between cards.

Hint: You do not need loops or lists of data for this assignment. Three separately written Container widgets are fine.

Step 6 — Add the button

Place a SizedBox and an ElevatedButton after the last schedule card.

Hint: button code
ElevatedButton(
  onPressed: () {
    print('Schedule button clicked');
  },
  child: Text('View Schedule'),
),

The message appears in the debug console/terminal, not on the app screen.

Step 7 — Run and test

Save main.dart, run your Flutter project on the emulator, and verify the title, profile, three cards, and button. If the app is already running from flutter run, save the file and press r in that terminal for hot reload.

Hint if you see overflow: Check unnecessary large gaps or long text. You may wrap the main Column in SingleChildScrollView if needed for a small screen. This is optional.

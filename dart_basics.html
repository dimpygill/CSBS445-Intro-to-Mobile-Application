What Is Code — and Why Does Dart Exist?

Before you write a single line, let's make sure you understand what code actually is and why Dart is the language Flutter uses.

What Is Code?

Code is simply a set of instructions you give to a computer, written in a language the computer understands.

Think of it like a recipe. A recipe tells a cook: "first do this, then do that, if the oven is hot enough do this." Code works exactly the same way — you write instructions, the computer follows them in order.

🍳
Real-world analogy
Code is like a recipe
A recipe says: "boil water, add pasta, wait 10 minutes, drain." Code says: "show a text box, wait for the user to type, when they tap Save, add it to the list." Both are just instructions — written in a language the reader understands.

What Is Dart?

Dart is the language Flutter uses. Think of it as the language you use to write your instructions in. Just like you can write a recipe in English or French, you can write app instructions in different programming languages. Flutter chose Dart.

What Does "Running Code" Mean?

When you "run" code, the computer reads your instructions from top to bottom and does what you said. If you said print("Hello"), it prints the word Hello. That's it.

print() is the simplest thing in Dart — it just shows a message. You'll use it a lot while learning to check what your code is doing.

📄 The simplest Dart program
print("Hello, world!");
Output
Hello, world!

That's your first line of Dart. It tells the computer: show the words "Hello, world!" on the screen.

Notice the semicolon ; at the end. In Dart, every instruction ends with a semicolon — it's like a full stop at the end of a sentence. Forgetting it is the most common beginner mistake.

⚠️
The semicolon rule: Every line of code in Dart ends with ; — just like every English sentence ends with a full stop. If you forget it, Dart will show an error.

📦 Lesson 2

Variables — Storing Information

A variable is a labelled box that holds a piece of information. It's one of the most important concepts in all of programming.

📦
Real-world analogy
A variable is a labelled box
Imagine a box with a label "Student Name" stuck on it. You put the name "Alex" inside. Any time you need the name, you look in that box. If the name changes to "Jordan", you put a new name in the same box. That's exactly what a variable does.

Creating a Variable in Dart

Here's how you create a variable and put something in it:

📄 Creating variables
String studentName = "Alex"; print(studentName);
Output
Alex
PartPlain English Meaning
StringThe type of the box — this box holds text. (More on types in the next lesson.)
studentNameThe name of the box — what you call it. You choose this name.
=The equals sign puts something into the box. Read it as "is set to".
"Alex"The value — what's inside the box. Text always goes inside quote marks.
;The semicolon — the full stop at the end of every Dart instruction.
print(studentName)Shows what's inside the studentName box on screen.

Changing a Variable

Once you've created a variable, you can change what's inside it:

📄 Changing a variable's value
String studentName = "Alex"; print(studentName); ← prints Alex studentName = "Jordan"; ← put a new value in the box print(studentName); ← now prints Jordan
Output
Alex Jordan
💡
When you change a variable, you don't write the type again. You only write String (or whatever type) the very first time you create the variable.

Why Are Variables Useful in Your App?

In your Student Task Manager project, you'll use variables to remember things like:

  • The text the user typed in the task name field
  • Which priority button they selected (High / Medium / Low)
  • Whether a task is marked done or not

Without variables, the app couldn't remember anything the user does.

🏷️ Lesson 3

Types of Data

Not all information is the same. A name is different from a number. A yes/no answer is different from both. Dart needs to know which type of data goes in each box.

🗃️
Real-world analogy
Different boxes for different things
You wouldn't store soup in a paper bag or a book in a fish tank. Different things need the right kind of container. In Dart, different types of data need the right type of variable.

The 4 Types You Need to Know

📝
String — Text
Any words, sentences, or characters. Always inside quote marks.

Example: "Alex", "High", "Submit project"
🔢
int — Whole Number
Any number without a decimal point. No quotes.

Example: 5, 20, 100, -3
💰
double — Decimal Number
Any number with a decimal point.

Example: 3.7, 9.99, 0.5
🔘
bool — True or False
Only two possible values: true or false. Like a light switch — on or off.

Example: true, false
📄 All four types in use
String taskName = "Submit homework"; int taskCount = 3; double progress = 0.75; ← 75% done bool isDone = false; ← not done yet print(taskName); ← Submit homework print(taskCount); ← 3 print(isDone); ← false
Output
Submit homework 3 false

Which Types Will You Use in the Project?

In your Student Task Manager you'll use:

  • String — the task name the user types, and the priority ("High", "Medium", "Low")
  • bool — whether each task is done or not (true = done, false = not done)

One Important Rule — Types Must Match

You can't put text into a number box. Dart will refuse and show an error.

📄 ❌ This will cause an error
int age = "twenty"; ← ERROR! "twenty" is text, not a number
📄 ✅ This is correct
int age = 20; ← correct: number in number box String word = "twenty"; ← correct: text in text box

🚦 Lesson 4

If / Else — Making Decisions

Your app needs to do different things depending on what happens. If the task is done — show a tick. If not — show an empty box. That's if/else.

🚦
Real-world analogy
If/else is like a traffic light decision
"If the light is green, drive. Otherwise (else), stop." Your code works exactly the same way — "if this condition is true, do this. Otherwise, do that."

If / Else in Dart

📄 Basic if/else
bool taskDone = true; if (taskDone) { print("✅ Task is complete!"); } else { print("⬜ Task is not done yet."); }
Output (because taskDone is true)
✅ Task is complete!
PartPlain English Meaning
if (taskDone)"If taskDone is true…" — check the condition inside the brackets.
{ ... }The curly brackets hold the code to run if the condition is true.
else"Otherwise…" — runs if the condition was false.
{ ... } after elseThe code to run if the condition was false.

Comparing Values

You can also compare two values using == (double equals — means "is equal to"):

📄 Checking a specific value
String priority = "High"; if (priority == "High") { print("🔴 This task is urgent!"); } else { print("This task can wait."); }
Output
🔴 This task is urgent!
⚠️
Single = vs double ==
= puts a value INTO a variable. (assignment)
== COMPARES two values. (question: "are these equal?")
This is one of the most common beginner mistakes — using = when you meant ==.

Where You'll See This in the Project

In your Task Manager, if/else appears in two places:

  • Checking if the task name is empty before saving: if (name.isEmpty) return;
  • Deciding whether to cross out a task name: if isDone == true, show a strikethrough

📋 Lesson 5

Lists — Storing Multiple Items

A variable holds one thing. But what if you need to store 10 tasks? That's what a List is for — it holds many items in one place.

📋
Real-world analogy
A List is like a shopping list
Instead of writing each item on a separate piece of paper, you write them all on one list. You can add items, remove items, or look up any item by its position. A Dart List works exactly the same way.

Creating a List

📄 A list of tasks
List<String> tasks = [ "Math homework", "Read Chapter 4", "Submit project", ];
PartPlain English Meaning
List<String>A list where every item is a String (text). The type inside < > tells Dart what kind of items the list holds.
tasksThe name of the list. You choose this name.
[ ... ]Square brackets hold all the items. Items are separated by commas.
"Math homework"The first item in the list (at position 0).

Getting Items From a List

Every item has a position number — called an index. The first item is at position 0 (not 1!).

📄 Accessing list items
print(tasks[0]); ← first item print(tasks[1]); ← second item print(tasks[2]); ← third item
Output
Math homework Read Chapter 4 Submit project
⚠️
Lists start at 0, not 1. This confuses almost every beginner. If you have 3 items, their positions are 0, 1, and 2. There is no position 3 — asking for it will crash the app!

Adding and Removing Items

📄 Changing the list
// Add a new item to the end tasks.add("Study for exam"); // Remove an item by position tasks.removeAt(0); ← removes "Math homework" // How many items are in the list? print(tasks.length); ← prints 3

Where You'll See This in the Project

Your entire Task Manager is built around a list. Every time the user adds a task, it goes into the list with .add(). The screen shows all items in the list. That's it.

🔧 Lesson 6

Functions — Reusable Instructions

Instead of writing the same code over and over, you put it in a function and give it a name. Call the name whenever you need it.

🎰
Real-world analogy
A function is like a vending machine
You press a button (call the function), put in a coin (pass in a value), and get a snack out (receive a result). The machine does the same job every time, but you don't need to know how it works inside — you just use it.

A Simple Function

📄 Creating and calling a function
// Create the function void sayHello() { print("Hello! Welcome to the app."); } // Call (use) the function sayHello(); ← runs the code inside sayHello(); ← runs it again
Output
Hello! Welcome to the app. Hello! Welcome to the app.
PartPlain English Meaning
voidThis function doesn't give anything back — it just does something (prints). "void" means "returns nothing".
sayHelloThe name of the function. You choose this.
( )The brackets are where you put inputs (called parameters). Empty here means no inputs needed.
{ ... }The code the function runs when called.
sayHello();This is how you call (run) the function — write the name followed by ().

A Function That Takes Input

You can pass information into a function. The placeholder is called a parameter.

📄 Function with a parameter
void greetStudent(String name) { print("Welcome, " + name + "!"); } greetStudent("Alex"); ← prints: Welcome, Alex! greetStudent("Jordan"); ← prints: Welcome, Jordan!
Output
Welcome, Alex! Welcome, Jordan!

Where You'll See This in the Project

In your Task Manager, functions are used constantly — Flutter calls them automatically for you. For example:

  • When the user taps the checkbox, Flutter calls a function you wrote that changes isDone
  • When the user taps Save, a function runs that adds the task to the list
  • When the user taps Cancel, a function runs that closes the screen

🏗️ Lesson 7

Classes & Objects — Grouping Things Together

A class is a blueprint. From one blueprint you can create many objects. In Flutter, every widget — every button, every text box, every screen — is built from a class.

🏠
Real-world analogy
A class is like a house blueprint
A blueprint describes what a house looks like — how many rooms, where the doors are. From one blueprint, you can build many houses. Each house is its own separate building (object), but they all share the same structure. In Dart, a class is the blueprint; an object is one house built from it.

Why Do You Need to Know This?

In Flutter, every screen you create is a class. Every button is created from a class. When you write Scaffold(...) or Text("Hello"), you are using classes that Flutter built for you. You also create your own classes for screens.

A Simple Class

📄 A basic class
class Task { String name; bool isDone; Task(this.name, this.isDone); }
PartPlain English Meaning
class TaskWe're defining a blueprint called "Task".
String nameEvery task has a name (text).
bool isDoneEvery task has a done flag (true or false).
Task(this.name, this.isDone)The constructor — the instructions for building one task. You provide the name and done status when creating it.

Creating Objects From a Class

Once you have the blueprint, you can create as many tasks as you want:

📄 Creating objects from the Task class
// Create two task objects from the Task blueprint Task task1 = Task("Math homework", false); Task task2 = Task("Read Chapter 4", true); print(task1.name); ← Math homework print(task2.isDone); ← true
Output
Math homework true

Flutter Screens Are Classes Too

When you write a Flutter screen, it looks like this — and now you understand what it means:

📄 A Flutter screen is a class
class HomeScreen extends StatefulWidget { // This is a blueprint for the Home screen // "extends StatefulWidget" means it can change over time }
💡
extends means "is a type of". HomeScreen extends StatefulWidget means "HomeScreen is a type of StatefulWidget". Flutter knows how to work with StatefulWidgets — so by extending it, your screen gets all of Flutter's screen-management features for free.

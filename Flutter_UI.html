Flutter UI: Build a Student Profile Screen

Learn to translate a screen idea into a widget tree, then into readable Flutter code. Each step adds only one small idea.

1. How Flutter creates a UI

Flutter builds screens by combining widgets. A widget describes a piece of the interface, such as text, a button, spacing, or a layout. Widgets can contain other widgets, creating a widget tree.

MaterialApp is a Flutter widget that sets up app-wide features for a Material Design interface, such as themes, navigation support, and default styling for Material widgets. It does not make Flutter cross-platform; Flutter itself supports multiple platforms.

What does MaterialApp provide?

Think of MaterialApp as the outer wrapper that prepares common app-level settings. It does not draw the entire screen by itself. We put a Scaffold inside its home parameter to build the visible page.

Important distinction: Flutter is the cross-platform UI framework. MaterialApp selects Material Design app behavior; it is not what makes the app run on Android and iOS.

Our code:

MaterialApp(
  home: Scaffold(
    appBar: AppBar(
      title: Text('Student Profile'),
    ),
    body: Center(
      child: Text('Welcome!'),
    ),
  ),

Widget tree:

MaterialApp
└── home: Scaffold
    ├── appBar: AppBar
    │   └── title: Text("Student Profile")
    └── body: Center
        └── child: Text("Welcome!")

Here, MaterialApp, Scaffold, AppBar, Center, and Text are widgets. home, appBar, body, title, and child are parameters.

What is home in MaterialApp?

home is a named parameter of MaterialApp, not a widget. It tells Flutter which widget to display as the app's initial screen when the application starts.

In our Student Profile app, we write home: Scaffold(...). This means: When the app starts, display the screen built using this Scaffold.

MaterialApp(
  home: Scaffold(
    appBar: AppBar(
      title: Text('Student Profile'),
    ),
    body: Center(
      child: Text('Welcome!'),
    ),
  ),
)

Visual widget tree:

MaterialApp                 ← Widget
└── home: Scaffold          ← home is a parameter; Scaffold is a widget
    ├── appBar: AppBar
    │   └── title: Text('Student Profile')
    └── body: Center
        └── child: Text('Welcome!')

Remember: home does not mean the Android Home button, the phone's home screen, or a separate Flutter widget called Home. It simply specifies the initial screen of your Flutter app.

Scaffold provides a standard screen layout. AppBar is the top bar. body is the main screen area.

3. Step 1 — App shell

Tree before code:

MaterialApp
└── Scaffold
    ├── appBar: AppBar
    │   └── title: Text("Student Profile")
    └── body: Center
        └── child: Text("Welcome!")

Every indentation level means a widget nested inside its parent. The appBar and body are two different Scaffold parameters.

import 'package:flutter/material.dart';

void main() {
  runApp(
    MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          backgroundColor: Colors.yellow,
          title: Text('Student Profile'),
          centerTitle: true,
        ),
        body: Center(
          child: Text('Welcome!'),
        ),
      ),
    ),
  );
}

Read the closing brackets: Text closes first, then Center, Scaffold, MaterialApp, and runApp.

4. Step 2 — Display several lines with Column

To show more than one item vertically, replace Center's single Text with a Column. A Column takes children: [ ... ], a list of widgets.

MaterialApp
└── Scaffold
    ├── AppBar
    │   └── Text("Student Profile")
    └── Center
        └── Column
            ├── Text("Welcome!")
            ├── Text("Name: Alex")
            └── Text("Course: Flutter UI")

Replace only the body:

body: Center(
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    children: [
      Text('Welcome!'),
      Text('Name: Alex'),
      Text('Course: Flutter UI'),
    ],
  ),
),

mainAxisAlignment positions the Column's items along its vertical axis. Notice: Center has one child (the Column); the Column has three children.

6. Step 4 — Add an ElevatedButton

An ElevatedButton is a clickable widget. It requires onPressed (what happens when tapped) and child (what appears on the button). For now, the button can have an empty action.

MaterialApp
└── Scaffold
    ├── AppBar → Text("Student Profile")
    └── Center
        └── Column
            ├── Text("Welcome!")
            ├── SizedBox
            ├── Text("Name: Alex")
            ├── SizedBox
            ├── Text("Course: Flutter UI")
            ├── SizedBox
            └── ElevatedButton
                └── child: Text("View Profile")
SizedBox(height: 12),
ElevatedButton(
  onPressed: () {
    print('Profile button tapped');
  },
  child: Text('View Profile'),
),

onPressed is a parameter containing a function. The button is interactive, but we are not changing the screen or introducing state yet.

7. Complete working main.dart

Copy this entire code into lib/main.dart and run flutter run. After edits, save and press r in the running terminal for hot reload.

import 'package:flutter/material.dart';

void main() {
  runApp(
    MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          backgroundColor: Colors.yellow,
          title: Text('Student Profile'),
          centerTitle: true,
        ),
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Text('Welcome!'),
              SizedBox(height: 12),
              Text('Name: Alex'),
              SizedBox(height: 12),
              Text('Course: Flutter UI'),
              SizedBox(height: 12),
              ElevatedButton(
                onPressed: () {
                  print('Profile button tapped');
                },
                child: Text('View Profile'),
              ),
            ],
          ),
        ),
      ),
    ),
  );
}

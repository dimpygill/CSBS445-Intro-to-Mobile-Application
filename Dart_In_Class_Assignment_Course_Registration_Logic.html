Dart In-Class Assignment

Course Registration Logic

Practice: variables, Lists, loops, if statements, continue, and break

Assignment Goal
Build the programming logic behind a simple mobile course-registration application using Dart only. You are not building the Flutter user interface yet.
Why are we doing this?
Later in the course, we will combine Dart with the Flutter framework to build mobile applications. The logic you practice in this assignment—storing course data, looping through courses, making decisions, skipping unavailable courses, calculating totals, and stopping processing when needed—is the same kind of logic that can later be connected to a Flutter user interface.
Due Date: Thursday, October 8, 2026.
Work on this assignment during class. If you do not finish it during class, complete it outside class and upload your completed Dart program by Thursday.

Problem

A college wants to create a mobile application that helps a student review courses and build a registration plan. Before we create the mobile interface, we need to write and test the registration logic in Dart.

Your program will work with a list of courses. For each course, the program must decide whether the course is available, determine whether adding it would exceed the student's credit limit, and build a list of courses that the student can register for.

Course Data

Use the following course information in your program. You may choose an appropriate Dart structure to represent the data, but your program must use a List.

Program Requirements

  1. Create the course data shown above and store it in a List.
  2. Create an empty List named something similar to selectedCourses to store the courses that are successfully added.
  3. Create a variable to keep track of the student's total registered credits.
  4. Use 16 credits as the maximum credit limit.
  5. Use a loop to process the courses one at a time.
  6. Use an if statement to check whether a course is available.
  7. If a course is not available:
    • Print a message identifying the unavailable course.
    • Use continue; so the program skips the remaining registration logic for that course and moves to the next course.
  8. Before adding an available course, check whether: 
    current total credits + course credits > maximum credits
  9. If adding the course would exceed the maximum:
    • Print a message explaining that the credit limit would be exceeded.
    • Use break; to stop the registration-processing loop.
  10. Otherwise:
    • Add the course to selectedCourses.
    • Add its credits to the running total.
    • Print a confirmation message.
  11. After the loop finishes, display:
    • the selected courses, and
    • the final number of registered credits.

Required Use of Dart Concepts

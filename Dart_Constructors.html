Dart Constructors: 9 Ways to Write Them

Beginner-friendly examples of implicit default, explicit traditional, parameterized, shorthand, named, optional, initializer-list, redirecting, and factory constructors.

How to use: Each example is a separate, complete Dart program. Run one example at a time.

1. Implicit default constructor (Dart provides it)

If a class declares no constructor, Dart automatically supplies an unnamed, zero-argument constructor.

class Price {
  int amount = 0; // Field has a default value
  // No constructor is written here.
}

void main() {
  Price p = Price(); // Calls the implicit default constructor
  print(p.amount);
}
Output: 0
Dart only provides this implicit constructor when you have not declared any constructor.

2. Explicit zero-argument constructor (traditional block body)

Write the class name followed by parentheses and a body. This is the most familiar constructor style.

class Price {
  int amount = 0;

  Price() { // Explicit constructor; runs on object creation
    amount = 100; // Initialize the field
  }
}

void main() {
  Price p = Price();
  print(p.amount);
}
Output: 100

3. Traditional parameterized constructor (assign fields in body)

Pass a value to the constructor and assign it to a field inside the constructor body.

class Price {
  late int amount; // Assigned before first use

  Price(int startingAmount) {
    amount = startingAmount; // Traditional assignment
  }
}

void main() {
  Price p = Price(250);
  print(p.amount);
}
Output: 250

4. Field-formal parameter shorthand (this.field)

Dart can declare a constructor parameter that initializes an instance field directly, avoiding a separate assignment.

class Price {
  int amount;

  Price(this.amount); // Shorthand for initializing amount
}

void main() {
  Price p = Price(250);
  print(p.amount);
}
Output: 250
Compare examples 3 and 4: both produce the same result; example 4 is shorter.

5. Named constructors (multiple ways to create objects)

Dart does not support traditional constructor overloading by parameter signatures. Instead, use named constructors.

class Price {
  int amount;

  Price(this.amount); // Unnamed constructor

  Price.free() : amount = 0; // Named constructor

  Price.discounted(int original)
      : amount = original - 20; // Another named constructor
}

void main() {
  print(Price(100).amount);
  print(Price.free().amount);
  print(Price.discounted(100).amount);
}
Output:
100
0
80

6. Optional named parameters with defaults

Use braces { } in the parameter list and a default value. This allows readable object creation.

class Price {
  int amount;
  String currency;

  Price({this.amount = 0, this.currency = 'USD'});
}

void main() {
  Price first = Price(); // Both defaults
  Price second = Price(amount: 75); // Override one default
  print('${first.amount} ${first.currency}');
  print('${second.amount} ${second.currency}');
}
Output:
0 USD
75 USD

7. Initializer list (initialize before constructor body)

An initializer list starts with a colon :. It is useful for initializing final fields and for computing initial values.

class Price {
  final int amount;
  final int tax;

  Price(int base)
      : amount = base,
        tax = base ~/ 10 { // Integer division: 10% tax
    print('Constructor body runs');
  }
}

void main() {
  Price p = Price(100);
  print(p.amount + p.tax);
}
Output:
Constructor body runs
110

8. Redirecting constructor (reuse another constructor)

A constructor can redirect to another constructor of the same class using : this(...).

class Price {
  int amount;

  Price(this.amount); // Main constructor

  Price.zero() : this(0); // Redirects to Price(0)
}

void main() {
  print(Price(30).amount);
  print(Price.zero().amount);
}
Output:
30
0

9. Factory constructor (controls object creation)

A factory constructor returns an object rather than directly initializing this. It can choose which instance to return.

class Price {
  final int amount;

  Price._(this.amount); // Named private constructor (library-private)

  factory Price.nonNegative(int value) {
    // Replace negative inputs with zero.
    return Price._(value < 0 ? 0 : value);
  }
}

void main() {
  print(Price.nonNegative(40).amount);
  print(Price.nonNegative(-5).amount);
}
Output:
40
0

Dart OOP Concepts

Welcome! This comprehensive guide is designed specifically for developers coming from a C# or Java background. We will explore how Dart handles Classes, Objects, Method Syntax Variations, Visibility (Public/Private), constructor alternatives to overloading, and crucial constructor rules.

1. Classes and Objects

Just like in C# and Java, a Class is a blueprint for creating objects, and an Object is an instance of that class.

class Rectangle {
  int width = 0;
  int height = 0;

  // Method
  int calculateArea() {
    return width * height;
  }
}

void main() {
  // Creating an object (no 'new' keyword required in Dart, though optional)
  Rectangle rect = Rectangle();
  rect.width = 10;
  rect.height = 5;
  print("Area: ${rect.calculateArea()}"); // Area: 50
}

2. Ways to Write Methods & Getters in Dart

In Dart, you can write computations as standard methods, arrow-syntax methods, or read-only getters. Here is how they compare:

A. Traditional Body Syntax (Standard Method)

Uses explicit curly braces {} and return keyword, requiring parentheses () when called.

class Rectangle {
  int width = 0;
  int height = 0;

  int calculateArea() {
    return width * height;
  }
}

// Usage:
// print(rect.calculateArea()); // Parentheses () are required!

B. Arrow Syntax (Expression Body Shorthand)

For single-expression methods, Dart offers the arrow operator =>.

int calculateArea() => width * height;

C. Getter Syntax (Read-Only Property)

When a method takes no parameters and computes a value, defining it with the get keyword allows callers to access it like a field or property without parentheses ().

class Rectangle {
  int width = 0;
  int height = 0;

  // Getter form
  int get area => width * height;
}

// Usage:
// print(rect.area); // Notice: No parentheses ()!

3. Standard Constructor Bodies vs. Methods

Just like in C# and Java, a constructor can be written with a standard body using curly braces Rectangle(int w, int h) { ... } to execute custom initialization logic. Important Rule: You cannot nest method definitions inside a constructor body; constructors and methods must be separate members inside the class.

class Rectangle {
  int width = 0;
  int height = 0;

  // 1. Standard Constructor Body (used for initialization)
  Rectangle(int w, int h) {
    width = w;
    height = h;
    print("Rectangle created with width: $width and height:$height");
  }

  // 2. Regular Method (defined separately in the class body)
  int calculateArea() {
    return width * height;
  }
}

void main() {
  Rectangle rect = Rectangle(10, 5);
  print("Area: ${rect.calculateArea()}"); // Area: 50
}

4. Public and Private Members & Shorthand Constructors

Unlike C# (which uses public, private keywords) or Java:

  • Public: By default, all variables, methods, and classes in Dart are public. No keyword is needed.
  • Private: Dart has library-level privacy. You make a member private by prefixing its name with an underscore (_). It can only be accessed within the same file (library).

Dart Shorthand Constructors (Initializing Formals)

Instead of manually writing repetitive assignment statements inside the constructor body, Dart lets you use this.fieldName directly in the parameter list. This automatically assigns arguments to fields—even private fields like `this._balance`!

class BankAccount {
  String accountHolder; // Public
  double _balance;      // Private (accessible only within this file)

  // Shorthand Constructor: Automatically assigns parameters to fields
  BankAccount(this.accountHolder, this._balance);

  // Getter to securely read private balance
  double get balance => _balance;
  
  // Method to modify private state
  void deposit(double amount) {
    if (amount > 0) _balance += amount;
  }
}

5. Constructor Initializer Lists (Exclusive to Constructors)

Dart constructors can include an Initializer List placed after a colon (:) before the constructor body runs. This syntax is strictly exclusive to constructors and cannot be used in regular methods or functions.

class Point {
  final double x;
  final double y;

  // Constructor Initializer List (sets fields before body runs)
  Point() : x = 0.0, y = 0.0;
}

6. The Default Constructor Rule & Multiple Constructors

Part A: How the Default Constructor Works Normally

If you write a class and do not define any constructors at all, Dart automatically provides a hidden, parameterless default constructor behind the scenes (e.g., `Rectangle()`). This allows you to instantiate the class without passing any arguments.

class Rectangle {
  int width = 0;
  int height = 0;
  // No custom constructor written here. Dart provides Rectangle() automatically.
}

void main() {
  var r = Rectangle(); // Works fine because of the automatic default constructor!
}

Part B: Multiple Constructors using Named Constructors

Having multiple constructors in a class is fully supported in Dart! Since Dart does not support traditional constructor overloading (multiple constructors with the exact same name), Dart achieves this using **Named Constructors** (e.g., `Rectangle.square(...)`).

Here is an example with a parameterized constructor and a named constructor that runs without errors because we are properly passing arguments to the constructors we defined:

class Rectangle {
  int width;
  int height;

  // Parameterized Constructor
  Rectangle(this.width, this.height);

  // Named Constructor for a square
  Rectangle.square(int size) : width = size, height = size;
}

void main() {
  var r1 = Rectangle(10, 5);      // Calls the parameterized constructor successfully!
  var r2 = Rectangle.square(4); // Calls the named constructor successfully!
}

Part C: When Does an Error Occur? (The Missing Parameterless Constructor)

Crucial Rule (Same in C# & Java): The moment you explicitly define any custom constructor (such as our parameterized `Rectangle(this.width, this.height)`), Dart stops generating the automatic parameterless default constructor.

Therefore, if you try to instantiate the class without passing arguments like `Rectangle()`, Dart will throw a compile-time error:

class Rectangle {
  int width;
  int height;

  Rectangle(this.width, this.height);
}

void main() {
  // ❌ COMPILE ERROR! The parameterless default constructor was suppressed.
  // var r = Rectangle(); 

  // ✅ Correct:
  var r2 = Rectangle(10, 20); 
}

7. Constructor Overloading: C#/Java vs. Dart

Feature C# / Java Dart
Constructor Overloading Supported (multiple constructors with same name, different parameters). Not Supported. You cannot have multiple constructors with the exact same name.
Alternative Solution N/A Uses Named Constructors (e.g., Rectangle.dimensions(...)) or optional/named parameters.

Example of Dart Named Constructors:

class Point {
  double x, y;

  // Default Constructor using Initializer List
  Point() : x = 0.0, y = 0.0;

  // Named Constructor 1
  Point.origin() : x = 0.0, y = 0.0;

  // Named Constructor 2
  Point.fromJson(Map<String, double> json) 
      : x = json['x'] ?? 0.0, y = json['y'] ?? 0.0;
}

void main() {
  var p1 = Point();
  var p2 = Point.origin();
  var p3 = Point.fromJson({'x': 10.0, 'y': 20.0});
}

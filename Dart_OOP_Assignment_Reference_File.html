1. What is Object-Oriented Programming (OOP)?

OOP organizes a program around objects. A class describes what an object knows (fields) and what it can do (methods). A Dart program can create many objects from one class.

Dart example
class Book {
  String title;
  int pages;

  Book(this.title, this.pages);

  void describe() {
    print('$title has $pages pages.');
  }
}

void main() {
  Book firstBook = Book('The Blue Planet', 120);
  firstBook.describe();
}
Expected output
The Blue Planet has 120 pages.
Key idea: Book is the class; firstBook is an object. title and pages are fields; describe() is a method.

2. Fields, methods, and constructors

A constructor initializes a new object. Its name matches the class name. The shorthand this.field assigns constructor arguments directly to fields.

Dart example
class Student {
  String name;
  int grade;

  Student(this.name, this.grade);

  void introduce() {
    print('I am $name, in grade $grade.');
  }
}

void main() {
  Student student = Student('Maya', 11);
  student.introduce();
}
Expected output
I am Maya, in grade 11.
Key idea: Student(this.name, this.grade) is a generative constructor. this.name refers to the object’s field.

3. Inheritance: extends and super

Inheritance allows a child class to reuse behavior defined in a parent class. Use extends when the child truly is a kind of parent. Use super(...) to call the parent constructor.

Dart example
class Vehicle {
  String brand;

  Vehicle(this.brand);

  void start() {
    print('$brand is starting.');
  }
}

class Car extends Vehicle {
  int doors;

  Car(String brand, this.doors) : super(brand);

  void showDoors() {
    print('Doors: $doors');
  }
}

void main() {
  Car car = Car('Honda', 4);
  car.start();
  car.showDoors();
}
Expected output
Honda is starting.
Doors: 4
Key idea: Car inherits start() from Vehicle. It also defines its own showDoors(). Prefer a small, meaningful hierarchy over inheritance everywhere.

4. Method overriding and @override

A child class can provide its own implementation of an inherited method. The method name and compatible signature stay the same. The @override annotation makes the intention explicit.

Dart example
class Animal {
  void makeSound() {
    print('An animal makes a sound.');
  }
}

class Dog extends Animal {
  @override
  void makeSound() {
    print('Woof!');
  }
}

class Cat extends Animal {
  @override
  void makeSound() {
    print('Meow!');
  }
}

void main() {
  Dog dog = Dog();
  Cat cat = Cat();
  dog.makeSound();
  cat.makeSound();
}
Expected output
Woof!
Meow!
Key idea: The child version runs instead of the parent version for that child object. Overriding is different from overloading.

5. Calling a parent method with super

The super keyword can also call the parent implementation of an overridden method. This is useful when you want to extend rather than completely replace the parent behavior.

Dart example
class Employee {
  void showRole() {
    print('Works at the company');
  }
}

class Manager extends Employee {
  @override
  void showRole() {
    super.showRole();
    print('Also manages a team');
  }
}

void main() {
  Manager manager = Manager();
  manager.showRole();
}
Expected output
Works at the company
Also manages a team
Key idea: super.showRole() invokes the parent method before the child adds extra behavior.

6. Polymorphism: one parent type, many child objects

Polymorphism means the same method call can behave differently depending on the actual object. A variable or List typed as a parent can hold objects of its child classes.

Dart example
class Shape {
  void draw() {
    print('Drawing a shape');
  }
}

class Circle extends Shape {
  @override
  void draw() {
    print('Drawing a circle');
  }
}

class Square extends Shape {
  @override
  void draw() {
    print('Drawing a square');
  }
}

void main() {
  List<Shape> shapes = [Circle(), Square()];

  for (Shape shape in shapes) {
    shape.draw();
  }
}
Expected output
Drawing a circle
Drawing a square
Key idea: shape has the parent type Shape, but Dart runs the overridden method belonging to the actual object. Inheritance enables this example, but the two concepts are not identical.

7. Overriding versus overloading in Dart

Overriding changes an inherited method. Dart does not support Java/C#-style overloading by declaring multiple methods with the same name but different parameter lists. Instead, Dart provides optional positional and named parameters.

Dart example
class Greeting {
  void sayHello(String name, [String greeting = 'Hello']) {
    print('$greeting, $name!');
  }
}

void main() {
  Greeting greeting = Greeting();
  greeting.sayHello('Ava');
  greeting.sayHello('Ava', 'Good morning');
}
Expected output
Hello, Ava!
Good morning, Ava!
Key idea: This is one method with an optional positional parameter, not traditional method overloading. The square brackets make the second argument optional.

8. Lists: storing several values

A List<T> stores ordered values. Indexes begin at 0. A normal for loop is useful when displaying numbered choices.

Dart example
void main() {
  List<String> fruits = ['Apple', 'Banana', 'Orange'];

  for (int i = 0; i < fruits.length; i++) {
    print('${i + 1}. ${fruits[i]}');
  }

  print('First item: ${fruits[0]}');
}
Expected output
1. Apple
2. Banana
3. Orange
First item: Apple
Key idea: i + 1 displays user-friendly numbering; fruits[i] still uses zero-based indexes.

9. Maps: keys and values

A Map<K,V> associates a key with a value. Use containsKey() to check whether a key exists and square brackets to access or update a value.

Dart example
void main() {
  Map<String, int> inventory = {
    'Pencils': 10,
    'Notebooks': 4
  };

  if (inventory.containsKey('Pencils')) {
    inventory['Pencils'] = inventory['Pencils']! + 5;
  }

  print('Pencils: ${inventory['Pencils']}');
  print('Notebooks: ${inventory['Notebooks']}');
}
Expected output
Pencils: 15
Notebooks: 4
Key idea: The ! tells Dart that the value is not null. Use it only when the value is known to exist. Maps are useful for counting and accumulating values.

10. Nested Maps: grouping data by a key

A nested Map stores a Map inside another Map. For example, a school can track scores by class and student. This example is deliberately different from the assignment.

Dart example
void main() {
  Map<String, Map<String, int>> scores = {};

  scores['Math'] = {};
  scores['Math']!['Ava'] = 80;
  scores['Math']!['Noah'] = 90;

  scores['Science'] = {};
  scores['Science']!['Ava'] = 95;

  print(scores['Math']!['Ava']);
  print(scores['Science']!['Ava']);
}
Expected output
80
95
Key idea: The outer key identifies the group; the inner key identifies a value within that group. The same student can have separate scores in different subjects.

11. Accumulating values instead of duplicating them

To add repeated values together, check whether the key already exists. If it does, update the stored number. Otherwise, create a new entry.

Dart example
void main() {
  Map<String, int> votes = {};
  List<String> responses = ['Blue', 'Red', 'Blue'];

  for (String response in responses) {
    if (votes.containsKey(response)) {
      votes[response] = votes[response]! + 1;
    } else {
      votes[response] = 1;
    }
  }

  print('Blue: ${votes['Blue']}');
  print('Red: ${votes['Red']}');
}
Expected output
Blue: 2
Red: 1
Key idea: This pattern is called aggregation. It is useful whenever repeated input should update an existing total.

12. Console input with dart:io

Use import 'dart:io'; to access standard input and output. stdout.write() keeps the cursor on the same line; stdin.readLineSync() reads text.

Dart example
import 'dart:io';

void main() {
  stdout.write('What is your favorite color? ');
  String color = stdin.readLineSync() ?? '';
  print('You chose $color.');
}
Expected output
What is your favorite color? Green
You chose Green.
Key idea: readLineSync() returns String?, so ?? '' supplies an empty string when no text is returned.

13. Converting input and preventing crashes

User input arrives as text. int.tryParse() safely converts a numeric string into an integer; invalid text returns null. Validate before using the number.

Dart example
import 'dart:io';

void main() {
  stdout.write('Enter your age: ');
  String input = stdin.readLineSync() ?? '';
  int? age = int.tryParse(input);

  if (age == null) {
    print('Please enter a whole number.');
  } else if (age <= 0) {
    print('Age must be positive.');
  } else {
    print('Age accepted: $age');
  }
}
Expected output
Enter your age: abc
Please enter a whole number.
Key idea: Use tryParse rather than parse when input may be invalid. A question mark in int? means the variable may contain null.

14. Repeating menus with while, if/else, and break

A while loop can keep a console program running until the user chooses to exit. break ends the loop; continue starts the next iteration.

Dart example
import 'dart:io';

void main() {
  while (true) {
    print('1. Say hello');
    print('2. Exit');
    stdout.write('Choice: ');

    String choice = stdin.readLineSync() ?? '';

    if (choice == '1') {
      print('Hello!');
    } else if (choice == '2') {
      print('Goodbye!');
      break;
    } else {
      print('Invalid option.');
    }
  }
}
Expected output
1. Say hello
2. Exit
Choice: 1
Hello!
1. Say hello
2. Exit
Choice: 2
Goodbye!
Key idea: The loop repeats until break. Invalid choices should display a message instead of terminating the program unexpectedly.

15. Checking dates with DateTime

A date string can look correct but represent an impossible calendar date. Split the text into year, month, and day, then compare the resulting DateTime components to the originals.

Dart example
void main() {
  String input = '2026-02-30';
  List<String> parts = input.split('-');

  int year = int.parse(parts[0]);
  int month = int.parse(parts[1]);
  int day = int.parse(parts[2]);

  DateTime date = DateTime(year, month, day);

  if (date.year == year &&
      date.month == month &&
      date.day == day) {
    print('Valid date');
  } else {
    print('Invalid date');
  }
}
Expected output
Invalid date
Key idea: DateTime normalizes out-of-range components, so checking the fields afterward catches dates such as February 30. Before splitting, verify the YYYY-MM-DD format to avoid errors on malformed input.

16. Checking the format with RegExp

A regular expression can check whether text follows a pattern. It does not by itself prove that a calendar date exists.

Dart example
void main() {
  RegExp pattern = RegExp(r'^\d{4}-\d{2}-\d{2}$');

  print(pattern.hasMatch('2026-10-30'));
  print(pattern.hasMatch('10/30/2026'));
  print(pattern.hasMatch('2026-02-30'));
}
Expected output
true
false
true
Key idea: Use both format validation and DateTime validation. The r before the string creates a raw string, making backslashes easier to write.

17. Organizing responsibilities across classes

Classes should have clear jobs. One class may describe a domain object; another may store and manage a collection of objects. Do not create child classes unless they represent a meaningful is-a relationship.

Dart example
class Product {
  String name;
  double price;

  Product(this.name, this.price);
}

class ShoppingCart {
  List<Product> products = [];

  void addProduct(Product product) {
    products.add(product);
  }

  void showProducts() {
    for (Product product in products) {
      print('${product.name}: \$${product.price}');
    }
  }
}

void main() {
  ShoppingCart cart = ShoppingCart();
  cart.addProduct(Product('Pen', 2.5));
  cart.showProducts();
}
Expected output
Pen: $2.5
Key idea: ShoppingCart contains Product objects; it does not extend Product. This is composition, a useful alternative to unnecessary inheritance.

18. Running and testing a Dart console file

Save a Dart program with the .dart extension. Open the terminal in the folder containing that file, then run the command below. Test normal input, repeated input, and invalid input.

Dart example
dart --version

dart run example.dart
Key idea: Use dir *.dart in Windows PowerShell to confirm the filename. When a filename has spaces, enclose it in quotation marks. Console data stored only in memory is lost when the program ends.

1. What is a dictionary in Dart?

In Dart, a dictionary is called a Map. It stores key–value pairs: use a key to find its associated value. Keys are unique; different keys may have the same value. No import is needed for Map because it belongs to dart:core.

KeyValue
id101
nameAlex
age20
majorComputer Science

Example

void main() {
  Map<String, Object> student = {
    'id': 101,
    'name': 'Alex',
    'age': 20,
    'major': 'Computer Science',
  };
  print(student['name']);
}

Expected output

Alex

3. Create typed, inferred, and empty maps

Use explicit types to make your intention clear. With var, Dart infers the types from the initial entries. A typed literal begins with <KeyType, ValueType>. Map<String, int>() is a constructor call; <String, int>{} is a literal.

Example

void main() {
  Map<String, int> a = {'Alex': 90};
  var b = {'Sara': 85}; // Inferred Map<String, int>.
  var c = <String, int>{}; // Empty typed map literal.
  var d = Map<String, int>(); // Empty map constructor.
  c['John'] = 95;
  print(a);
  print(b);
  print(c);
  print(d);
}

Expected output

{Alex: 90}
{Sara: 85}
{John: 95}
{}

4. Access values and handle missing keys

  1. Put the key inside square brackets.
  2. A missing key returns null.
  3. For Map<String, int>, a lookup has type int?, even when you expect the key to exist.
  4. Use ?? to provide a fallback, or check the looked-up value for null.

Why is the lookup type int?

int? means an integer or null. The question mark marks a nullable type. Map<String, int> stores integer values, but looking up a key might find no entry. A missing key returns null, so the lookup result has type int?. This applies even when you know that Alex is present.

Map<String, int> scores = {'Alex': 90};

print(scores['Alex']); // 90: the key exists.
print(scores['Sara']); // null: the key does not exist.

int? score = scores['Alex']; // Allowed: accepts an integer or null.
// int score = scores['Alex']; // Error: int? cannot be assigned to int.

int safeScore = scores['Alex'] ?? 0; // 90
int missingScore = scores['Sara'] ?? 0; // 0

Read ?? 0 as: “Use the retrieved value; if it is null, use 0.” This gives the whole expression a non-null integer result that can be stored in an int variable.

Example

void main() {
  var scores = {'Alex': 90};
  int? alex = scores['Alex'];
  int david = scores['David'] ?? 0;
  print(alex);
  print(scores['David']);
  print(david);
  if (alex != null) {
    print(alex + 5);
  }
}

Expected output

90
null
0
95

5. Add and update entries

The same assignment syntax adds a missing key or replaces the value of an existing key. It does not create duplicate entries for that key.

Example

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  scores['John'] = 95; // Add.
  scores['Alex'] = 98; // Update.
  print(scores);
}

Expected output

{Alex: 98, Sara: 85, John: 95}

6. Understand built-in methods and callbacks

Built-in methods versus your functions

A dictionary in Dart is a Map. A method is a function called through an object. Methods such as scores.update() are supplied by Dart; you do not define them. A function such as increaseScore() is one you write yourself.

Some Map methods need your function to decide what to do with a value. This supplied function is called a callback. Pass the function name without parentheses; the Map method calls it with the appropriate arguments.

update(): one existing value

update() finds the key, sends its old value to your function, stores the returned value, and returns that new value. For Alex, it calls increaseScore(90). A missing key throws an error unless you provide ifAbsent.

// A standard named function: you write this.
int increaseScore(int oldScore) {
  return oldScore + 5;
}

void main() {
  Map<String, int> scores = {'Alex': 90};
  print(scores);

  // update() is a built-in Map method.
  // It gets 90 from the map and calls increaseScore(90).
  // increaseScore returns 95; update stores 95 under 'Alex'.
  int newScore = scores.update('Alex', increaseScore);
  print(newScore);
  print(scores);
}

Expected output

{Alex: 90}
95
{Alex: 95}

update() with ifAbsent

ifAbsent is a predefined named parameter. Its function takes no arguments and returns the value to insert if the key is missing. The update callback is not called for a missing key.

int increaseScore(int oldScore) {
  return oldScore + 5;
}

int startingScore() {
  return 80;
}

void main() {
  var scores = {'Alex': 90};
  scores.update('John', increaseScore, ifAbsent: startingScore);
  print(scores);
}

Expected output

{Alex: 90, John: 80}

Three ways to write the same callback

The following alternatives perform the same update. Choose one; running all three would add 15.

// Named function (defined above):
scores.update('Alex', increaseScore);

// Anonymous function with a standard body:
scores.update('Alex', (int oldScore) {
  return oldScore + 5;
});

// Anonymous function with arrow syntax:
scores.update('Alex', (oldScore) => oldScore + 5);

oldScore is a parameter name you can choose. => means the function returns the result of the single expression that follows.

7. Remove entries

remove() deletes by key and returns the removed value, or null if absent. removeWhere() deletes entries matching a condition. clear() removes all entries.

Example

void main() {
  var scores = {'Alex': 90, 'Sara': 55, 'John': 95};
  print(scores.remove('John'));
  scores.removeWhere((name, score) => score < 60);
  print(scores);
  scores.clear();
  print(scores);
}

Expected output

95
{Alex: 90}

9. Loop through a map

A Map is not itself an Iterable. Loop through keys, values, or entries. An entry exposes key and value. Map.forEach() calls a function with both.

Example

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  for (var name in scores.keys) {
    print(name);
  }
  for (var score in scores.values) {
    print(score);
  }
  for (var entry in scores.entries) {
    print('${entry.key}: ${entry.value}');
  }
  scores.forEach((name, score) {
    print('$name scored $score');
  });
}

Expected output

Alex
Sara
90
85
Alex: 90
Sara: 85
Alex scored 90
Sara scored 85

10. Order and safe iteration

Ordinary map literals and Map() preserve insertion order. Updating an existing key keeps its position. Removing and then adding it places it at the end. Other implementations can have different ordering rules.

Avoid adding or removing keys while iterating over the map. Use removeWhere() for conditional deletion, or iterate over a copy of the keys.

Example

void main() {
  var scores = {'Alex': 90, 'Sara': 55};
  for (var name in scores.keys.toList()) {
    if ((scores[name] ?? 0) < 60) {
      scores.remove(name);
    }
  }
  print(scores);
}

Expected output

{Alex: 90}

11. Combine maps

addAll() modifies the receiving map. The spread operator (...) copies entries into a new map. When a key repeats, the later value wins. These are shallow copies: nested mutable objects remain shared.

Example

void main() {
  var first = {'Alex': 90};
  var second = {'Alex': 95, 'Sara': 85};
  var combined = {...first, ...second};
  print(first);
  print(combined);
  first.addAll(second);
  print(first);
}

Expected output

{Alex: 90}
{Alex: 95, Sara: 85}
{Alex: 95, Sara: 85}

12. Transform entries with map()

Map is a type; map() is a method. The method builds a new map from the MapEntry objects returned by its callback. The original remains unchanged. Transformed keys must stay unique if you want to retain every entry.

Example

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  var adjusted = scores.map(
    (name, score) => MapEntry(name, score + 5),
  );
  print(scores);
  print(adjusted);
}

Expected output

{Alex: 90, Sara: 85}
{Alex: 95, Sara: 90}

13. Mixed types, nullable values, and dynamic

Map<String, Object> permits mixed non-null values while retaining type checking when values are used. Object? also permits null. dynamic permits mixed values and postpones many checks until runtime. Prefer specific types where practical.

With nullable values, a null lookup can mean either an absent key or a stored null. containsKey() distinguishes them.

Example

void main() {
  Map<String, Object> student = {
    'name': 'Alex', 'age': 20, 'gpa': 3.8, 'enrolled': true,
  };
  var name = student['name'];
  if (name is String) {
    print(name.toUpperCase());
  }
  Map<String, int?> scores = {'Alex': null};
  print(scores['Alex']);
  print(scores.containsKey('Alex'));
  print(scores.containsKey('Sara'));
}

Expected output

ALEX
null
true
false

14. Nested maps

A nested map stores other maps as values. First look up the record, then a field. The null-aware index operator ?[] skips the second lookup if the first returns null.

Example

void main() {
  Map<String, Map<String, Object>> students = {
    'S101': {'name': 'Alex', 'age': 20, 'gpa': 3.8},
    'S102': {'name': 'Sara', 'age': 21, 'gpa': 3.9},
  };
  print(students['S101']?['name']);
  print(students['S102']?['gpa']);
  print(students['S999']?['name'] ?? 'Not found');
}

Expected output

Alex
3.9
Not found

15. Lists of maps

A list of maps stores records by position. A nested map stores records by identifier. Choose based on how you need to access the records.

Example

void main() {
  List<Map<String, Object>> students = [
    {'id': 101, 'name': 'Alex', 'gpa': 3.8},
    {'id': 102, 'name': 'Sara', 'gpa': 3.9},
  ];
  print(students[0]['name']);
  for (var student in students) {
    print('${student['name']}: ${student['gpa']}');

16. Maps and functions

A function can accept or return a map. Dart passes arguments by value; for objects, that value is a reference. The function can therefore modify the same map object. Reassigning the function parameter does not reassign the caller’s variable.

Example

Map<String, int> createScores() {
  return {'Alex': 90};
}

void addScore(Map<String, int> scores, String name, int score) {
  scores[name] = score;
}

void main() {
  var scores = createScores();
  addScore(scores, 'Sara', 85);
  print(scores);
}

Expected output

{Alex: 90, Sara: 85}

Example

void main() {
  final scores = {'Alex': 90};

  const fixed = {'Alex': 90};

  print(scores);
  print(fixed);
  print(readOnly);
}

18. Maps and JSON

A Dart map and JSON text are different things. JSON is a text format used for files and APIs. Import dart:convert to encode a map as JSON or decode JSON. JSON object keys must be strings and values must be JSON-compatible. jsonDecode() returns dynamic; validate external data before relying on its structure.

Example

import 'dart:convert';

void main() {
  var student = {'name': 'Alex', 'age': 20};
  String jsonText = jsonEncode(student);
  print(jsonText);
  Map<String, dynamic> decoded =
      jsonDecode(jsonText) as Map<String, dynamic>;
  print(decoded['name']);
}

Expected output

{"name":"Alex","age":20}
Alex

19. Complete example: grade management

This program adds records, searches by name, calculates an average, and removes a record. The empty-map average returns 0 by an explicit design choice.

Example

void addStudent(Map<String, int> grades, String name, int grade) {
  grades[name] = grade;
}

void displayStudents(Map<String, int> grades) {
  for (var entry in grades.entries) {
    print('${entry.key}: ${entry.value}');
  }
}

double calculateAverage(Map<String, int> grades) {
  if (grades.isEmpty) return 0;
  int total = 0;
  for (int grade in grades.values) {
    total += grade;
  }
  return total / grades.length;
}

void searchStudent(Map<String, int> grades, String name) {
  int? grade = grades[name];
  if (grade == null) {
    print('Student not found');
  } else {
    print('$name scored $grade');
  }
}

void main() {
  var grades = <String, int>{};
  addStudent(grades, 'Alex', 90);
  addStudent(grades, 'Sara', 85);
  addStudent(grades, 'John', 95);
  print('All students:');
  displayStudents(grades);
  searchStudent(grades, 'Sara');
  print('Average: ${calculateAverage(grades).toStringAsFixed(1)}');
  grades.remove('John');
  print('After deletion:');
  displayStudents(grades);
}

Expected output

All students:
Alex: 90
Sara: 85
John: 95
Sara scored 85
Average: 90.0
After deletion:
Alex: 90
Sara: 85

24. Built-in Map methods: complete examples

Each example is a separate console program. Copy one complete example at a time. Section 6 explains update() in detail.

addAll(): add another map

Copies all entries into the receiving map. Existing keys are overwritten. It returns void (no useful result).

void main() {
  var scores = {'Alex': 90};
  scores.addAll({'Alex': 95, 'Sara': 85});
  print(scores);
}

Expected output

{Alex: 95, Sara: 85}

addEntries(): add MapEntry objects

MapEntry holds one key and one value. addEntries() accepts an Iterable of entries, such as a list. Existing keys are overwritten; the method returns void.

void main() {
  var scores = {'Alex': 90};
  scores.addEntries([
    MapEntry('Sara', 85),
    MapEntry('John', 95),
  ]);
  print(scores);
}

Expected output

{Alex: 90, Sara: 85, John: 95}

containsKey() and containsValue(): check presence

Each returns bool (true or false). containsKey() checks keys; containsValue() checks values. String keys are case-sensitive.

void main() {
  var scores = {'Alex': 90};
  print(scores.containsKey('Alex'));
  print(scores.containsKey('alex'));
  print(scores.containsValue(90));
  print(scores.containsValue(100));

putIfAbsent(): insert only when missing

If the key exists, it returns the existing value and does not call your function. If missing, it calls your zero-argument function, inserts its result, and returns that result.

int startingScore() {
  return 80;
}

void main() {
  var scores = {'Alex': 90};
  print(scores.putIfAbsent('Alex', startingScore));
  print(scores.putIfAbsent('Sara', startingScore));
  print(scores);
}

Expected output

90
80
{Alex: 90, Sara: 80}

updateAll(): update every value

Calls your function for each entry with two arguments: key and old value. Each returned value replaces that entry’s value. updateAll() returns void.

int increaseEveryScore(String name, int oldScore) {
  return oldScore + 5;
}

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  scores.updateAll(increaseEveryScore);
  print(scores);
}

Expected output

{Alex: 95, Sara: 90}

forEach(): perform an action for each pair

Calls your function with the key and value. Your function returns void; it can print or perform another action. forEach() does not replace values with callback results. Do not add or remove keys during this traversal.

void displayScore(String name, int score) {
  print('$name scored $score');
}

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  scores.forEach(displayScore);
}

Expected output

Alex scored 90
Sara scored 85

map(): create a transformed map

Calls your function with each key and value. Your function must return a MapEntry. The method returns a new map; the original is unchanged. If transformed keys collide, entries are overwritten.

MapEntry<String, int> adjustEntry(String name, int score) {
  return MapEntry(name, score + 5);
}

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  Map<String, int> adjusted = scores.map(adjustEntry);
  print(scores);
  print(adjusted);
}

Expected output

{Alex: 90, Sara: 85}
{Alex: 95, Sara: 90}

remove(): delete by key

Deletes one entry and returns its previous value. If the key is missing, it returns null. For Map, its return type is int?.

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  int? removed = scores.remove('Sara');
  print(removed);
  print(scores.remove('John'));
  print(scores);
}

Expected output

85
null
{Alex: 90}

removeWhere(): delete matching entries

Calls your function with each key and value. Return true to remove an entry; return false to keep it. The method returns void.

bool isFailing(String name, int score) {
  return score < 60;
}

void main() {
  var scores = {'Alex': 90, 'Sara': 55, 'John': 95};
  scores.removeWhere(isFailing);
  print(scores);
}

Expected output

{Alex: 90, John: 95}

clear(): empty the map

Removes every entry. The map variable still refers to the same map object, which is now empty. It returns void.

void main() {
  var scores = {'Alex': 90};
  scores.clear();
  print(scores);
  print(scores.isEmpty);
}

Expected output

{}

cast(): view a map with specified types

Advanced: returns a typed view, not a converted copy. Values are not converted (a string “90” does not become integer 90). Incompatible entries cause errors when accessed through the view. Changes through this view affect the original map.

void main() {
  Map<Object, Object> original = {'Alex': 90};
  Map<String, int> scores = original.cast<String, int>();
  scores['Alex'] = 95;
  print(original);
  print(scores);
}

Expected output

{Alex: 95}
{Alex: 95}

Map.castFrom(): static typed view

Advanced: a static method is called on Map itself. Like cast(), castFrom() adapts a map to different declared key and value types without converting the entries. The view shares the underlying map; incompatible entries can fail at runtime.

void main() {
  Map<Object, Object> original = {'Alex': 90};
  var scores = Map.castFrom<Object, Object, String, int>(original);
  print(scores['Alex']);
}

Expected output

90

Inherited from Object. Returns a String representation; print(scores) uses this representation automatically. This text is not JSON.

void main() {
  var scores = {'Alex': 90};

25. Map properties and operators

Properties are read without parentheses. Operators provide special syntax rather than method names.

void main() {
  var scores = {'Alex': 90, 'Sara': 85};
  print(scores.length); // 2
  print(scores.isEmpty); // false
  print(scores.isNotEmpty); // true
  print(scores.keys.toList()); // [Alex, Sara]
  print(scores.values.toList()); // [90, 85]
  for (var entry in scores.entries) {
    print('${entry.key}: ${entry.value}');
  }
  print(scores['Alex']); // [] lookup: 90, with type int?.
  scores['Alex'] = 95; // []= assignment: add or replace.
}

keys, values, and entries are iterable views. toList() here belongs to Iterable, not Map.

Inherited properties: runtimeType describes the object’s runtime type; its printed name may vary by platform. hashCode returns an integer used for hashing, not a summary of the entries.

Ordinary Dart maps use object identity for ==; two separate maps with the same entries are not automatically equal. A map compares equal to itself. The inherited noSuchMethod() participates in handling missing members and normally throws; it is not an operation for manipulating entries.

26. Map constructors: ways to create a map

A constructor creates an object. These are different from methods called on an existing map.

Map(), Map.of(), and Map.from()

Map() creates an empty map. Map.of() copies a map with compatible declared types. Map.from() can copy from a broadly typed map and checks entries against the requested types at runtime. Copies are shallow.

void main() {
  var empty = Map<String, int>();
  var original = {'Alex': 90};
  var copy = Map<String, int>.of(original);
  Map<Object, Object> broad = {'Sara': 85};
  var checked = Map<String, int>.from(broad);
  copy['Alex'] = 95;
  print(empty);
  print(original);
  print(copy);
  print(checked);
}

Expected output

{}
{Alex: 90}
{Alex: 95}
{Sara: 85}

Map.fromEntries()

Creates a new map from MapEntry objects. Duplicate keys use the last supplied value.

void main() {
  var scores = Map<String, int>.fromEntries([
    MapEntry('Alex', 90),
    MapEntry('Sara', 85),
  ]);
  print(scores);
}

Expected output

{Alex: 90, Sara: 85}

Map.fromIterables()

Pairs the first key with the first value, and so on. Both iterables must contain the same number of elements, or it throws an error. Repeated keys are overwritten.

void main() {
  var names = ['Alex', 'Sara'];
  var grades = [90, 85];
  var scores = Map<String, int>.fromIterables(names, grades);
  print(scores);
}

Expected output

{Alex: 90, Sara: 85}

Map.fromIterable()

Creates keys and values from each element of one iterable. The key and value callbacks each receive that element. If a callback is omitted, the element itself is used for that part.

String useName(dynamic element) {
  return element as String;
}

int nameLength(dynamic element) {
  return (element as String).length;
}

void main() {
  var lengths = Map<String, int>.fromIterable(
    ['Alex', 'Sara'], key: useName, value: nameLength,
  );
  print(lengths);
}

Expected output

{Alex: 4, Sara: 4}

Map.identity()

Advanced: compares keys using identical() rather than ordinary equality. Two distinct objects can be separate keys even when their == says they are equal.

class Person {
  final String name;
  Person(this.name);

  @override
  bool operator ==(Object other) {
    return other is Person && other.name == name;
  }

  @override
  int get hashCode => name.hashCode;
}

void main() {
  var a = Person('Alex');
  var b = Person('Alex');
  var normal = <Person, int>{a: 90, b: 95};
  var identity = Map<Person, int>.identity();
  identity[a] = 90;
  identity[b] = 95;
  print(a == b);
  print(normal.length);
  print(identity.length);
}

Expected output

true

Map.unmodifiable() and Map.unmodifiableOf()

Both create shallow unmodifiable copies. unmodifiable() accepts a broadly typed source and checks types at runtime; unmodifiableOf() expects a source with compatible declared types. Attempts to add, update, or remove entries throw. unmodifiableOf() is listed in the current API; older SDKs may require unmodifiable().

void main() {
  var scores = {'Alex': 90};
  var first = Map<String, int>.unmodifiable(scores);
  var second = Map<String, int>.unmodifiableOf(scores);
  scores['Alex'] = 95;
  print(first);
  print(second);
  // first['Alex'] = 100; // Throws: map is unmodifiable.
}

Expected output

{Alex: 90}
{Alex: 90}

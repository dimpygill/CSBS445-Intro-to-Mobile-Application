Design a Campus Event Showcase

Build a creative, single-screen Flutter interface that promotes an upcoming campus event. The content requirements are fixed, but the visual design is entirely yours.

Your design challenge

Your college is hosting an event, and you have been asked to design its promotional screen for a mobile app. Create an attractive, easy-to-read interface that helps students quickly understand what the event is, when and where it happens, and why they should attend.

Choose your own event theme: a coding workshop, career fair, cultural festival, game night, art exhibition, science showcase, music performance, or another appropriate campus event. Invent realistic sample details for your event.

Creative freedom: There is no sample screen to copy and no required color scheme. You decide the layout, colors, typography, icons, section arrangement, and overall visual style. Every student’s screen may look different.

Required information on your screen

Your finished UI must clearly display all of the following:

  1. Event name — a prominent title.
  2. Event category or tagline — a short phrase describing the event.
  3. Date and time — both must be visible.
  4. Location — a building, room, or campus venue.
  5. Event description — at least two sentences explaining what attendees can expect.
  6. Three highlights — three distinct activities, benefits, or features of the event.
  7. Organizer — a department, club, or campus organization.
  8. One visual callout — for example, “Free Admission,” “Open to All Students,” or “Limited Seats.”

Flutter layout requirements

Use the tutorial to construct your screen. Your implementation must demonstrate:

  • Row to arrange at least two widgets horizontally.
  • Column to arrange multiple widgets vertically.
  • A nested layout — at least one Row inside a Column, or one Column inside a Row.
  • Card or Container to visually group or highlight information.
  • Padding and SizedBox or spacing to provide readable spacing.
  • Icon to visually represent at least one detail (such as date, location, or event type).
  • At least one deliberate use of mainAxisAlignment or crossAxisAlignment.

You may use additional widgets from the tutorial, including ListTile, Align, DecoratedBox, and SingleChildScrollView. The screen should remain readable on the emulator; use scrolling if necessary.

How to complete the assignment

  1. Review the Row, Column, nested layout, Card, Padding, Icon, and spacing examples in the provided interactive tutorial.
  2. Choose an event and write down the eight required pieces of information.
  3. Sketch your own screen layout on paper or plan it mentally. Decide which information belongs together.
  4. Create one Dart file and build the interface using Flutter widgets.
  5. Run the program in your Flutter emulator. Check alignment, spacing, readability, and whether all required information is visible (scroll if needed).
  6. Take a screenshot of the completed screen.
Scope: This is a UI design assignment. You do not need a database, navigation between screens, user input, working registration, or any backend functionality. A decorative “Register” or “Learn More” label is optional; it does not need to perform an action.

What to submit

Upload both files to the Canvas assignment:

  1. campus_event.dart — your complete Flutter source code.
  2. campus_event.png (or .jpg) — a screenshot of your UI running in the emulator.

Points: 1 — credit for submitting both the Dart file and a screenshot of the completed, running UI. This is an in-class practice activity focused on applying the tutorial and experimenting with your own design.

Before submitting

  • Does the screen include all eight required information items?
  • Did you use both Row and Column, including a nested layout?
  • Is the text readable, with appropriate padding and spacing?
  • Does the Dart file run, and does the screenshot show your actual UI?
  • Did you submit both required files?

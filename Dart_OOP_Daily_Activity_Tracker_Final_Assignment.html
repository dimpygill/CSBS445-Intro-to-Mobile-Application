My Daily Activity Tracker

Build a console-based program that records activities by date, combines repeated activity minutes, and displays daily history.

35Total points
14Test cases
2.5Points per test
.dartOnly submission

Assignment requirements

Develop this program in Dart console (not Flutter). The minimum requirements are a meaningful, limited use of inheritance, readable code, and basic documentation/comments. You may also use method overriding, polymorphism, constructors, Lists, Maps, and other relevant Dart features where they help. Do not add unnecessary inheritance layers.

Allow the user to add one of three activities, enter a valid calendar date in YYYY-MM-DD format, and enter a positive whole number of minutes. For the same activity on the same date, add the minutes and show the activity only once in history. Keep different dates separate. Reject invalid inputs without crashing.

Console display requirement: Show the activity description directly in the selection menu (for example, 1. Practice Dart: Review Inheritance). The following test transcripts specify the expected interface. You can use a different internal implementation, but the program must produce equivalent console behavior.

How the tests are presented

Each case shows Console interaction / test input on the left and Required output to verify on the right. Inputs appear after the exact console prompts. The right-hand text is supplied by the instructor; students do not need to write expected results or submit a test report.

Run each test in a fresh program session unless a case explicitly shows multiple actions in one session. Empty history is expected at the beginning of each new session. The application stores data in memory only; file/database persistence is not required.

14 graded test scenarios

Each test is worth 2.5 points. For multi-action tests, perform the complete sequence in the order shown. Blank lines in examples are for readability.

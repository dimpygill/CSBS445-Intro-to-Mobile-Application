1. Start with the Flutter boilerplate

Every program below is complete and independently runnable. Copy one program at a time into a Dart file inside your Flutter project’s lib folder. Run it from the project root using flutter run -t lib/filename.dart.

import 'package:flutter/material.dart';

void main() {
  runApp(
    MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('Example')),
        body: Row(
          children: [Text('First'), Text('Second')],
        ),
      ),
    ),
  );
}

import makes Flutter Material widgets available. main() is the Dart entry point. runApp() starts the widget tree. MaterialApp supplies Material application infrastructure. Scaffold provides the basic page layout. AppBar shows the top bar. body contains the main screen content. Row and Column arrange their children.

Class vs constructor: Row, Column, Card, Padding and Text are Flutter widget classes, not Dart keywords. Row(...) is a constructor call creating a widget configuration. child takes one widget; children takes a list of widgets.

Axis rule: In a Row, main = horizontal and cross = vertical. In a Column, main = vertical and cross = horizontal. Alignment values such as start and end depend on directionality where applicable.

The previews below are illustrative HTML renderings of expected layout, not live Flutter execution or exact device screenshots. Material colors, font metrics and shadows may vary by device/theme. All example programs use the same simple boilerplate.

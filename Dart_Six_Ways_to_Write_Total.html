Dart: Six Ways to Write a total() Calculation

All six approaches calculate 3 + 5 = 8. Compare method syntax, object creation, constructors, getters, and static methods. Each example below is a complete, independent Dart program.

Learning reference — 0 points. Read the examples and compare how each method is defined and called.

1. Expression Body (=>)

Use => when a method returns the value of one expression.

class Price {
  int total(int a, int b) => a + b; // Return the sum directly
}

void main() {
  print(Price().total(3, 5)); // Create object and call method
}
Output: 8

2. Block Body with return

Use braces and return to write the method body explicitly.

class Price {
  int total(int a, int b) {
    return a + b; // Return the calculated sum
  }
}

void main() {
  Price p = Price();          // Create an object
  int result = p.total(3, 5); // Call method
  print(result);             // Display 8
}
Output: 8

3. Block Body with a Local Variable

Store an intermediate result in a variable before returning it.

class Price {
  int total(int a, int b) {
    int sum = a + b; // Store intermediate result
    return sum;    // Return the result
  }
}

void main() {
  Price p = Price();         // Create an object
  print(p.total(3, 5));     // Call method and print 8
}
Output: 8

4. Constructor and Instance Fields

Pass values when creating the object. The method reads the object's stored fields instead of accepting parameters.

class Price {
  int a; // Instance field
  int b; // Instance field

  Price(this.a, this.b); // Constructor initializes fields

  int total() {
    return a + b; // Use the stored field values
  }
}

void main() {
  Price p = Price(3, 5); // Supply constructor values
  print(p.total());       // No method arguments needed
}
Output: 8

5. Getter

A getter calculates a value but is accessed like a property, without parentheses.

class Price {
  int a;
  int b;

  Price(this.a, this.b); // Initialize fields

  int get total => a + b; // Computed property
}

void main() {
  Price p = Price(3, 5); // Create an object
  print(p.total);         // Getter: NO parentheses
}
Output: 8

6. Static Method

A static method belongs to the class and can be called without creating an object.

class Price {
  static int total(int a, int b) {
    return a + b; // Calculate and return the sum
  }
}

void main() {
  print(Price.total(3, 5)); // Call using class name
}
Output: 8
Key differences: Methods 1–3 accept parameters; method 4 uses constructor-initialized fields; method 5 is a getter accessed without (); method 6 is static and does not require an object.

Dart Getters and Setters

A beginner-friendly reference with small programs, explanations, and outputs.

Getter: reads a property using get (no parentheses). Setter: changes a property using set (assignment syntax). The leading underscore in _amount means library-private in Dart.

Example 1 — Simple getter and setter

class Price {
  int _amount = 0; // Field that stores the price

  // SETTER: receives and stores a new value
  set amount(int value) {
    _amount = value;
  }

  // GETTER: returns the stored value
  int get amount {
    return _amount;
  }
}

void main() {
  Price p = Price(); // Create an object
  p.amount = 100;   // Calls the setter
  print(p.amount);  // Calls the getter
  p.amount = 250;   // Updates through setter
  print(p.amount);
}
Output
100
250
The same name, amount, can be used for both getter and setter. The syntax determines which one is called.

Example 2 — Setter with validation

class Price {
  int _amount = 0;

  // Reject negative prices
  set amount(int value) {
    if (value >= 0) {
      _amount = value; // Accept valid price
    } else {
      print('Price cannot be negative');
    }
  }

  // Short expression-body getter
  int get amount => _amount;
}

void main() {
  Price p = Price();
  p.amount = 100;  // Valid update
  print(p.amount);
  p.amount = -50;  // Rejected: amount stays 100
  print(p.amount);
}
Output
100
Price cannot be negative
100
A setter can enforce rules before changing data. Here, an invalid value leaves the previous price unchanged.

Example 3 — Constructor, getter, and setter

class Price {
  int _amount;

  // Constructor sets the initial price
  Price(this._amount);

  // Read the current price
  int get amount => _amount;

  // Change the price only if nonnegative
  set amount(int value) {
    if (value >= 0) {
      _amount = value;
    }
  }
}

void main() {
  Price p = Price(50); // Initial value: 50
  print(p.amount);    // Getter
  p.amount = 80;      // Setter
  print(p.amount);    // Getter again
}
Output
50
80
The constructor initializes the field; later assignments use the setter. Note that this constructor does not validate the initial value.

Example 4 — Read-only computed getter

class Cart {
  int price;
  int quantity;

  Cart(this.price, this.quantity);

  // Getter calculates a value; no setter needed
  int get total => price * quantity;
}

void main() {
  Cart cart = Cart(20, 3);
  print(cart.total); // 20 × 3 = 60
  cart.quantity = 4;
  print(cart.total); // 20 × 4 = 80
}
Output
60
80
A getter does not have to return a stored field. It can calculate a result whenever it is accessed.

Remember: Setters take one argument, have no return value, and use assignment syntax. Getters take no arguments and use property-access syntax.
